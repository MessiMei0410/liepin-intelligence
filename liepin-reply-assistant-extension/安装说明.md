# 猎聘专业回复助手

这是一个类似 E 简历形态的 Chrome 插件，用在猎聘职聊页。

## 安装

1. 打开 Chrome 的 `chrome://extensions/`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择这个文件夹：

```text
/Users/messi/Documents/Codex/2026-06-18/liepin-intelligence/liepin-reply-assistant-extension
```

## 使用

1. 打开猎聘职聊页：`https://h.liepin.com/im/showmsgnewpage`
2. 点开一个人选会话
3. 右下角会出现「猎聘专业回复助手」
4. 点击「生成回复」
5. 选择「复制」或「填入输入框」
6. 发送前人工看一眼，再手动发送
7. 如果已经打开「猎聘智能工作台」，点击「采纳修改」或「填入输入框」会自动同步到本地工作台；没打开也会先存在插件本地，后续刷新时同步。

## 当前能力

- 识别人选最新回复和当前会话信息
- 根据历史话术规则判断场景：
  - 问公司/问要求
  - 愿意进一步沟通
  - 交换微信/联系方式/简历
  - 薪资沟通
  - 不匹配/拒绝
  - 泛半导体触达
- 自动生成专业回复草稿
- 标出分数、风险和需要补的信息
- 支持复制和填入输入框
- 支持把采纳话术和填入动作自动同步到本机工作台

## 安全边界

- 不自动点击发送
- 不读取账号密码
- 不把 Cookie、Token、密码写入本地文档
- 插件只在猎聘职聊页加载
- 自动同步只写入 `http://127.0.0.1:8765` 本机服务，不对外发送
