# X-SaaS 人选推进助手

## 安装

1. 打开 Chrome 扩展管理页：`chrome://extensions/`
2. 打开右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本目录：
   `/Users/messi/Documents/Codex/2026-06-18/liepin-intelligence/xsaas-candidate-assistant-extension`

## 使用

- 打开 `https://headhunt.x-saas.com.cn/#/app/candidate/info/...`
- 右下角会出现“X-SaaS 人选推进助手”
- 先选择/填写客户与岗位，再检查姓名、公司、职位、学历、年限等字段
- 点击“入库预检”确认可写，再点“确认入库”
- 入库后可点“复核推进”或“确认停止”

## 状态口径

- 确认入库：`X1 X-SaaS入库/待复核`
- 复核推进：`X2 已复核/待人工联系`
- 确认停止：`H5 最近寻访/初筛不通过`
- X-SaaS 不自动记录猎聘触达，后续真实联系需要单独人工确认。
