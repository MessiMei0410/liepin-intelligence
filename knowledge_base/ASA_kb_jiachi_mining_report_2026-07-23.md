## 1. 这份文件对能力建设的意义

前两个 case（士兰微、长越）是"单岗位策略"样本；这份是**整个作战体系的切片**——它让知识库一次性获得三件单 case 给不了的东西：行业分类法、成批的目标公司锚点、负向规则的类型学。

## 2. 行业分类法（taxonomy，直接入库）

嘉驰内部已经在用一套半导体设备赛道的分类语言，ASA 知识库直接继承，不另造轮子：

- **行业攻坚方向**：前后道装备（75 家）/ 质量控制设备·量检测（51 家）/ Fab·封装厂（45 家）
- **赛道细分**：前道装备、量检测类、IDM、后道装备、FAB、测试类、光学延展类、OSAT、先进封装
- **赛道工艺分类**：61 个细分（刻蚀/CMP/CVD/Diff/光刻/PVD/ALD/PIE/图像视觉/运动控制/功率器件……）
- **职能方向**：工艺、机械、软件、设备EE、销售/市场/运营、厂务/生产管理、质量、算法、应用/AE/FAE、产品/项目、光学设计、管理岗
- **优先级语言**：P1明星 > PM重点 > PR最有可能成单 > P2瘦狗 > 暂缓/锁HC。**关键运营事实：1168 个职位里 354 个处于"暂缓/锁HC"**——策略 Agent 生成寻访前必须先查职位状态，否则三分之一的努力打在冻结职位上。

30 家客户在"竞争对手及目标公司"列填了真实目标池，这是策略 Agent 第 2 步最权威的校准数据。样本：

| 客户 | 目标公司池（客户原话） |

| 御微半导体 | 竞对：科磊、中科飞测、上海精测、上微、聚时；目标：科磊、中科飞测、昂图、维普光电（**注：精测、上微不能碰**） |
| 迈为科技（光学岗） | 上海微电子、舜宇光学、瑞声科技、中科飞测、高德红外、康耐视、匠岭、睿励、精测系、昂坤视觉等 |

## 4. 负向规则类型学（策略 Agent 必查清单）

从全簿归纳出五类排除规则（命中数为关键词匹配下限）：

| 类型 | 命中职位数 | 典型实例 |
| --- | --- | --- |
| 在职保护名单 | 50 | 长电/通富/沛顿/中芯/长存在职不推；重庆当地除万国不能挖；精测、上微不能碰 |
| 学历门槛 | 35 | 统招本科、最好一本以上 |
| 身份/背景限制 | 27 | 经理岗暂不看台湾人；只看大陆人（长存部分岗） |
| 竞业协议排除 | 15 | 长鑫竞业协议建议不推 |

**策略 Agent 的硬要求**：生成任何寻访策略时，排除规则必须逐类过一遍这张清单，并继承对应客户的既有保护名单。这不再是"注意事项"，是结构化约束。

## 6. 与 case 库的关系

- 士兰微（L1）：客户给了锚点 → 验证"有锚点时策略该怎么用"
