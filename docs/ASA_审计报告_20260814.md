## 三、审计发现

### P0-1：CI 形同虚设——后端测试路径错误 + 失败被吞（严重）

`.github/workflows/ci.yml` 后端 job：

```yaml
- name: Run backend tests
  run: |
    cd scripts && python3 -m pytest tests/ -x -q 2>/dev/null || echo "no backend tests yet"
```

**问题**：
1. `tests/` 目录在**仓库根**，不在 `scripts/` 下。实测 `cd scripts && python3 -m pytest tests/` 输出 `ERROR: file or directory not found: tests/`，**0 个测试真正运行**。
2. `2>/dev/null || echo "no backend tests yet"` 把 pytest 非零退出码吞掉，CI 永远显示成功——**后端 1100+ 测试在 CI 上零保护**。
3. 前端 job 同样被 `2>/dev/null || echo "no frontend tests yet"` 掩盖——vitest 失败也会被当作成功。

**影响**：PR 合并门禁完全不拦截回归。8-14 凌晨的后端测试漂移（见 P1-1）正是被它放过的。

### P1-1：后端测试漂移——行为已改、断言未同步（中等）

`tests/test_asa_copilot_intent.py::test_stopped_candidate_extended_stop_intent_produces_no_card` 失败：

```
AssertionError: assert 'candidate_action' not in {'answer': '已同步到 ASA：黄** 复核不通过...'}
```

**根因**（git 溯源确认）：`1228d05`（8-13 顾问式交互重构）把 `service.py` 中 `_candidate_action_already_applied` 命中时的 `pass`（普通问答）改为返回 `action_result`（`already_applied: True` + `candidate_action` 字段）。**行为是有意变更**（已停止人选的 stop 表达返回「已同步到 ASA：复核不通过」回执），但该测试断言没跟上，仍期望"不产生 candidate_action"。**非对方 02:45 提交引入**（8b32c84/0dfd6e7 未触及此逻辑）。

**同类已知漂移**（交接档案 2026-08-12 记录，均待修）：
