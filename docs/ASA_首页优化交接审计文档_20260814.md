## 1. 背景与目标

用户反馈「ASA 首页太复杂」。经诊断，原首页同一批待办数据渲染三遍（6 格数字概况 → lane 计数 → lane 列表），空板块占位、调试式标签、任务栏固定占 1/4 屏，信息密度过高。

**目标**：降低首屏信息密度 + 提升日常操作效率（打字、复制、任务管理、窄屏浮窗）。

### 3.2 关键实现契约（审计必读）

1. **任务栏折叠偏好**：localStorage key `asaTaskRailCollapsed`，`'0'`=展开，其余值/缺失=折叠。初始化 `useState(() => localStorage.getItem(...) !== '0')`；切换写 `'1'/'0'`。**e2e/单测 beforeEach 必须显式设 `'0'`**（否则任务栏交互用例挂）。
2. **消息 3 列布局**：`.agent-message` 为 `grid-template-columns:30px auto minmax(0,1fr)`（角色 | 时间 | 内容）。**消息内所有卡片/附件/名单触发器的 `grid-column` 均为 3**：`.agent-object`、`.sourcing-result-card`、`.agent-understanding-card/.agent-pending-intent/.agent-execution-receipt/.agent-suggested-actions/.agent-card-error`、`.candidate-list-card/.candidate-list-trigger(-row)`、`.agent-message-attachments`、`.agent-invalidated-notice`。改布局时全仓搜 `grid-column:2` 会误伤其他组件，只改 `.agent-message>` 前缀。e2e 断言 `gridColumn==='3'`。
3. **快捷指令发送链路**：`sendMessage(message)` 从 `submit()` 抽出（原 submit 主体）；`runQuickCommand` 先 `setDraft(command)` 再 `sendMessage(command)`。快捷指令定义在模块级 `agentHomeQuickCommands`（6 项：今日待办/过滤名单/人才地图/薪酬对标/推荐报告/继续寻访）。
4. **空 lane 过滤**：`workbenchLaneCount(workbench, lane) > 0` 才渲染（loading 时全部渲染防误判空）；计数以服务端 summary 为准（不受 300 窗口截断影响）。
5. **时间戳/相对时间**：模块级 `formatMessageTime`（同日 HH:mm 跨天补日期）、`dayLabelFor`（今天/昨天/日期）、`relativeTime`（刚刚/N 分钟前/N 小时前/N 天前）。
6. **输入框 auto-resize**：`useEffect [draft]` 中 `height='auto'` 后 `min(scrollHeight,160)`；发送清空 draft 自动回落。
7. **自动聚焦**：`composerFocusedRef` 保证只聚焦两次（首挂载 + 恢复完成），不抢焦点。
8. **浮窗修复**：L995 `@media(max-width:650px)` 内 `.agent-composer{grid-template-columns:44px minmax(0,1fr) 44px}`（原为 2 列 `1fr 44px` 残留），`.agent-attach,.agent-send{width:44px;height:44px}`。

## 7. Codex 复审与修正（2026-08-14）

### 7.1 审计发现

`571df91` 的 `src/app/App.tsx` 把错误/通知 toast 的两个 `useEffect` 放在
`if (error && !boot) return <Diagnostics ... />` 之后。首次启动失败进入诊断页时，
组件比正常界面少调用两个 Hook；重连恢复后会改变 Hook 调用顺序。当前 `eslint`
以 `react-hooks/rules-of-hooks` 报 2 个 error，因此原文“lint 0 错误”和
“`ci:fast` 已通过”不能作为该提交当前状态的有效证据。

### 7.2 修正

- 将两个 toast `useEffect` 移到诊断页条件 return 之前，保持所有渲染分支 Hook 顺序一致。
- 在 `src/__tests__/app-core-offline.test.tsx` 增加“首次启动失败进入诊断页，点击重新连接后恢复 Agent 首页”回归测试。
- 复核消息三列布局：内容、对象卡、寻访结果卡、结构化交互卡、候选名单卡/入口、附件和失效提示均落在第 3 列。
- 复核 390px 交互：任务抽屉无页面级横向溢出，输入区与消息卡功能测试通过。
