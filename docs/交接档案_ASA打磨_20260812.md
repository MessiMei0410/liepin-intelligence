## 五、核心改动 3：OpenCode Go 订阅配置（环境层，非仓库）

**坑**：opencode CLI 内置 `opencode-go` provider 是 console/OAuth 管理，不接受 API key → 一直 `Missing API key`。

**解法**：`~/.config/opencode/opencode.json` 自定义 provider `zen-go`：

```json
{
  "provider": {
    "zen-go": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://opencode.ai/zen/go/v1",
        "apiKey": "<OPENCODE_GO_API_KEY from ~/.hermes/.env>"
      },
      "models": { "glm-5": {}, "glm-5.2": {}, "kimi-k3": {}, "deepseek-v4-pro": {}, "deepseek-v4-flash": {}, "qwen3.8-max": {} }
    }
  }
}
```

用法：`opencode run "..." --model zen-go/glm-5`
⚠️ Hermes terminal 不读 ~/.zshrc，用 opencode 前需 `source ~/.hermes/.env` 或 key 已写入 config（本方案已写死，无需 env）。
