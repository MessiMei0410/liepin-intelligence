# 猎头 App 刷新

App 自带 SQLite 文件监听（`DispatchSourceFileSystemObject`），写入 `~/.hermes/talent_pool.db` 后会自动触发 `reloadData()`，**无需手动 pkill 或重启**。

## 自动刷新

- 任何写入 talent_pool.db 的操作（候选人入库、状态更新、搜索导入等）都会自动触发 App 刷新。
- 刷新时会保留当前选中的客户、岗位过滤和搜索文本，不会跳回第一个客户。
- 匹配报告生成完成后也会自动通知 App 刷新候选人列表。

## 手动刷新

如果自动刷新未生效或需要强制刷新：

- **快捷键**: `Cmd+R`
- **菜单**: 视图 → 刷新

## 注意事项

- ❌ 不再使用 `pkill` 暴力重启 App（之前的方式会导致窗口关闭再打开，体验差）
- ✅ 文件监听 + Cmd+R 手动刷新已完全覆盖所有场景
