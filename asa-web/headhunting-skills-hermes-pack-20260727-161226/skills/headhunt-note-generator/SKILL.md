# 猎头小红书笔记生成器

根据用户指定主题，一键生成笔记 + 竖版配图 → 存待发/ → 用户发布 → 移已发/。

## 完整工作流

```
用户给主题 → 生成笔记(.md) + 配图(.png)
                ↓
          存到 待发/笔记_xxx.md
          存到 待发/配图/0x_xxx.png
                ↓
          用户手动发布到小红书
                ↓
          笔记 → 移已发/
          配图 → 移已发/配图/
```

## 触发条件

- 用户说"生成一篇小红书笔记"、"写个猎头笔记"、"来一篇芯片/AI猎头的"
- 用户指定主题如"AI猎头"、"芯片猎头"、"猎头话术"等

## 生成步骤

### Step 1: 写笔记 (.md)

格式要求：
- **每篇 1-2 个技巧**，150-250 字
- 开头钩子：反常识/痛点问题，一句话抓人
- 文字生动有画面感，用比喻
- 每个技巧附一个可复制的 Prompt 模板
- 标签 3-5 个
- 保存路径：`~/Desktop/小红书/待发/笔记_[主题].md`

### Step 2: 生成配图 (.png)

- 竖版 1080×1440（3:4）
- 科技风渐变背景 + 装饰元素（电路/网络/标签等，与主题匹配）
- 标题大字（80px）居中偏上 + 文字阴影
- 副标题 38px
- 左上角主题标签胶囊
- 保存路径：`~/Desktop/小红书/待发/配图/0x_[主题简称].png`
- 完整代码模板见：`references/image-generation-pillow.md`

### Step 3: 用户发布后

```bash
# 笔记
mv ~/Desktop/小红书/待发/笔记_xxx.md ~/Desktop/小红书/已发/
# 配图
mv ~/Desktop/小红书/待发/配图/0x_xxx.png ~/Desktop/小红书/已发/配图/
```

## 目录结构

```
~/Desktop/小红书/
├── 待发/           ← 新笔记、新配图放这里
│   └── 配图/
├── 已发/           ← 发完移到这里
│   └── 配图/
```

## 内容原则

1. **每篇 1-2 个技巧**：一篇讲透一个点，多发几篇
2. **开头钩子**：一句话抓人
3. **文字生动**：有画面感，用比喻
4. **Prompt 真实可用**
5. **正文 150-250 字**
6. **标签 3-5 个**

## 注意事项

- 芯片/半导体方向要有专业深度
- 配图颜色与主题匹配（芯片=蓝紫、AI=紫、数据=绿）
- **配图代码模板**见 `references/cover-image-template.py`（三种装饰风格：circuit/network/tags）
- 用户说"直接发"时提醒：需手动上传图文
- 字数控制在 250 以内，方便小红书阅读
