# 谈薪反馈整理

属于猎头全流程 **阶段 5（谈薪）**——薪资协商过程，不是 Offer 阶段。薪资谈拢后进入阶段 6（Offer）。

用户口述谈薪沟通内容后，提取关键信息，生成结构化反馈文档存入 `~/Desktop/人才库/`。

## 触发条件

- 用户说"整理下谈薪反馈"、"整理下这个谈薪环节"、"把这个人选反馈整理一下"
- 用户口述一通跟候选人的薪资谈判沟通后要求存档
- 注意：只是薪资协商，还没最终敲定。敲定后走 Offer 流程

## 提取信息

从对话中识别以下要素：

| 维度 | 提取内容 |
|------|---------|
| 候选人 | 姓名 |
| 目标企业 | 我们推荐的公司 |
| 目标岗位 | 具体职位名称（用于浮窗匹配） |
| 竞争企业 | 候选人手上的其他机会（城市/公司） |
| 入职时间 | 脱敏期/竞业情况 + 对方领导态度 |
| 薪资状态 | 是否已敲定、候选人期望、差距 |
| 核心顾虑 | 候选人最看重什么（距离/薪资/平台/发展） |
| 决策时间线 | 候选人承诺何时给答复 |
| 风险点 | 丢单的主要威胁 |

## 内容原则

1. **原话保留**：候选人关键原话用引用块呈现，不加工
2. **SWOT 思维**：竞争分析要体现我方 vs 竞对的优劣势
3. **可执行**：下一步必须是具体动作，不是空泛建议
4. **简洁**：每个维度 2-4 行，不用长篇大论
