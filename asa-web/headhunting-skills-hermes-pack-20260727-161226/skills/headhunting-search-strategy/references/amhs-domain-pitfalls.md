# AMHS 半导体自动化 — 寻访陷阱

> 积累自：鹏新旭 AMHS软件专家(J10949) 寻访 2026-06-04

## 人才池现实

- 中国籍 AMHS 0→1 软件专家估计 < 100 人
- 核心人才集中在日本/台湾原厂：大福(Daifuku)、村田机械(Murata)、盟立(Mirle)、新代(SYNTEC)
- 猎聘上中国籍 AMHS 背景候选人极少，且大部分是碰巧简历提及 AMHS 的泛自动化/设备工程师

| 关键词 | 池大小 | 噪声率 | 说明 |

## 有效策略

1. **公司定向** → 优先搜 AMHS 原厂（大福/村田/盟立/新代）的在职/离职员工
2. **LinkedIn 补位** → 日系/台系原厂软件人才更可能在 LinkedIn
3. **台籍渠道** → 盟立总部在台湾，联电厦门联芯、台积电南京的台籍 AMHS 工程师
4. **客户预期管理** → 此类岗位建议 3-6 个月寻访周期

## 禁挖陷阱

鹏新旭禁挖名单含中芯南方/上海/东方/宁波、积塔半导体等，这些公司恰好有较强的 AMHS 团队。注意区分：中芯北京/北方/深圳/天津 可用。
