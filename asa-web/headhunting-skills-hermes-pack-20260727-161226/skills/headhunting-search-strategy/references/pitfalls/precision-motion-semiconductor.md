# 精密运动/半导体装备 — 搜索经验

## 关键词歧义

- `运动台`: ~50%噪声匹配运动品牌PM（安踏/李宁/特步），改用 `精密运动 半导体` 或 `精密运动平台`
- `Aerotech`: 匹配国产eVTOL公司"Volant Aerotech"，非美国精密运动公司，改用 `PI 精密运动` 或 `ETEL`
- `平台`: 在搜索时过于泛化，需搭配领域限定词如 `精密运动平台` 或 `位移平台`

- `运动台 产品经理`（无筛选）: 176人，~50%噪声
- `精密运动 产品经理 半导体`（硕士+上海）: 32人
- `精密运动 产品经理 半导体`（硕士+上海+苏州）: 待测

## 公司名歧义

- `Aerotech`: Volant Aerotech(览翌航空eVTOL) vs Aerotech Inc(美国精密运动)
- `ETEL`: 无歧义
- `PI`: 可能匹配其他缩写，但 `PI 纳米定位` 精度高

## 搜索策略建议

- 核心关键词优先用 `精密运动 产品经理` 而非 `运动台 产品经理`
- 公司定向搜索效果差（猎聘全文匹配），不如用技能关键词+筛选
- Zemax/光路关键词在运动台搜索中不如在光学PM搜索中有用
- 建议同步LinkedIn搜索"motion stage"/"wafer stage"/"precision motion"
