# AMHS 半导体领域寻访笔记

> 来源：鹏新旭 AMHS软件专家 (J10949) 寻访实战 — 2026-06-04

## 岗位理解

AMHS = Automated Material Handling System（自动化物料搬运系统），半导体 Fab 中负责晶圆在设备间自动运输的天车/轨道系统。

**核心软件组件**：
- **MCS** (Material Control System) — 物料调度控制系统，决定搬送路径和优先级
- **MCP** (Material Control Platform) — 底层平台，与天车硬件通讯
- **RTD** (Real-Time Dispatch) — 实时派工系统
- **OHT** (Overhead Hoist Transport) — 天车搬运系统的硬件端
