# X-SaaS (嘉驰内部系统) 搜索渠道

URL: https://headhunt.x-saas.com.cn/

## 特点

- 嘉驰国际内部招聘管理系统
- 候选人库规模较小（每人约 400 条记录）
- 支持芯片库/大工业库/互联网库等多库切换
- 搜索结果含完整联系方式（手机号）——这是猎聘没有的
- 有简历附件可以直接下载

## 与猎聘对比

| 维度 | 猎聘 | X-SaaS |
|------|------|--------|
| 候选人规模 | 百万级 | 数百级 |
| 联系方式 | 需付费查看 | 免费（手机号直接显示） |
| 简历详情 | CDP 提取 | 原始附件 |
| 搜索精度 | 关键词+筛选 | 公司名+职位+城市+行业 |
| 适合场景 | 大范围寻访 | 内部候选人管理+跟踪 |

## 使用方式

```python
# 通过 browser_navigate 登录
browser_navigate("https://headhunt.x-saas.com.cn/#/login")
# 填用户名/密码/隐私勾选 → 登录
# 进入候选人 → 公司名称搜"鹏新旭" → 立即搜索
```

## 注意事项

- 需要浏览器工具（非 CDP），该系统 SPA 较重
- 登录需勾选隐私声明才能点登录
- 芯片库和大工业库结果少，大库结果更全
