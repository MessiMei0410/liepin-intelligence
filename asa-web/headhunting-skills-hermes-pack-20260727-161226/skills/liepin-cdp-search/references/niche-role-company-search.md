# 极窄岗位公司定向搜索模式

针对全国人才池 < 200 人的极窄岗位（如 AMHS 软件专家），通用关键词搜索效率极低。

## 模式

跳过 R1-R4 通用关键词，直接搜索目标公司的在职/离职员工：

```
R1: 目标公司名（如"村田机械"、"盟立自动化"、"新代科技"）
R2: 目标公司 + 职能词（如"村田 软件"、"盟立 搬送"）
```

## AMHS 软件专家案例

**背景**：中国籍 AMHS 软件 0→1 专家估计 < 100 人，几乎全在日本/台湾原厂。

**搜索过程**：
- "AMHS" → 2700+ 条，但前 25 张卡片仅 2-3 个相关（全是碰巧简历中提到 AMHS 的设备工程师）
- "天车 半导体" → 3000+ 条，同样稀释严重
- "村田机械" → 500+ 条，直接命中原厂员工
- "盟立自动化" → 600+ 条
- "新代科技" → 221 条

**结论**：定向公司搜索命中率是通用关键词的 10-50 倍。

## 关键原则

1. 先查 AMHS 设备供应商名单（大福/Daifuku、村田/Murata、盟立/Mirle、新代/SYNTEC、SMC）
2. 用公司中文名搜索（日系公司中文名在猎聘上匹配度高）
3. 重点看"物流/仓储项目经理"、"产品经理"、"软件工程师"等职能，而非设备/工艺岗
4. 注意禁挖名单
