# 报告结构详细规范

## 全局样式

- 字体：英文 Calibri，中文 微软雅黑（通过 `w:eastAsia` 设置）
- 正文：10pt，#333，行距 1.25
- 页边距：上下 2.54cm，左右 3.18cm

## 各部分格式

### 封面
- 标题：26pt 加粗，颜色 #1A5276，居中
- 副标题：14pt，灰色 #787878
- 候选人与日期：11pt / 9pt

### 一、硬性门槛对照（表格）
- 3列：要求 | 候选人情况 | 判定
- 表头深蓝底 (#1A5276) 白字
- 数据行交替 #EBF5FB 底色
- 判定列：✅ 顶格 / ✅ 完全对口 / ✅ 远超 / ✅ 深度匹配

### 二、岗位职责逐条匹配
- 每条配星级：`'★' * n + '☆' * (5 - n)`
- JD 关键词灰字提示
- 候选人证据要点用缩进列表

### 三、加分项核查（表格）
- 3列：加分项 | 候选人情况 | 判定
- 判定：✅ / ⚠️

### 四、潜在风险与关注点
- 编号条目，加粗标题 + 正文说明
- 灰色评论性文字

### 五、综合匹配度评分
- 评分条：`'█' * n + '░' * (20 - n)`，n = pct/5
- 维度：教育背景、技术深度、行业经验、管理能力、产品思维
- 综合分大字居中，#1A5276

### 六、面试考察建议（表格）
- 2列：重点考察维度 | 建议问题方向
- 引号包裹的具体面试问题

### 七、初次电话沟通指南（猎头场景）
- 通话目的与定位
- 四阶段话术（破冰→摸底→匹配探测→收尾）
- 电话后评估清单（表格，含通过标准 + 红灯信号）
- 禁忌提醒（❌ 逐条）

### 八、结论
- 大字结论（如"🏆 强推面试"）
- 总结性段落
