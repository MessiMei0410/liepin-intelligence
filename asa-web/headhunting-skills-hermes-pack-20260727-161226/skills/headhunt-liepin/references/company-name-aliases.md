# 公司名称变体映射表

同一公司在不同招聘平台/系统中的展示名称不同，搜索时需覆盖所有变体。

## 鹏新旭 (Peng New旭)

| 平台 | 搜索关键词 |
|------|-----------|
| 猎聘 | `鹏新旭`（简称即可） |
| X-SaaS 大库 | `深圳市鹏新旭技术有限公司`（全称） |
| X-SaaS 芯片库 | `鹏新旭` |
| 通用 | `鹏新旭(PST)` `深圳鹏新旭技术有限公司` `鵬新旭技術有限公司` |

## 使用规则

- 猎聘搜索：用简称即可，猎聘会模糊匹配
- X-SaaS 搜索：用全称（公司名下拉框选"全部经历"后填入）
- 生成报告时：统一使用简称"鹏新旭"

## 新增公司

当发现新的目标公司时，在猎聘和 X-SaaS 各搜一次，记录两边的准确名称到此表。
