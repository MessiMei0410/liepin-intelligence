## 一、30 秒搞懂塑封机

芯片做出来后要用**环氧树脂包封**保护（transfer molding / 传递成型）。塑封机就是干这个的：**放芯片 → 合模 → 高温高压把树脂压进模具 → 保压固化 → 开模取出**，循环往复。追求**节拍短、无气泡、不溢料、不伤芯片**。

> 通俗类比：它像"高级注塑机"，但比普通注塑机讲究得多——模具精度高、压力控制精细、常需真空环境、芯片娇贵不能压坏。

## 二、机器上的"电"六大摊

| 子系统 | 要点 |
|---|---|
| 合模机构 | 数百吨压力，电驱（伺服）或液压，要求压力稳、位置准 |
| 注塑料筒（plunger） | 树脂下压进模具，**速度/压力曲线精确**——塑封质量核心 |
| 机械手/进出料 | 多轴联动，快且准 |
| 模具温控 | 百余度恒温，均匀性影响固化质量 |
| 控制大脑 | PLC + 触摸屏/上位机（三菱/西门子/基恩士常见；日系来源机型三菱多） |
| 安全系统 | 光幕、双启动等法规硬要求 |

## 三、能力分档（猎头对照表）

| 档次 | 年限 | 能力表现 |
|---|---|---|
| 初级（能干活的） | 1-3 年 | 配盘接线、看图、跟班调机、简单 PLC、按手册设伺服参数 |
| **中级（能当家的）** | 4-8 年 | **独立调试多轴伺服**（抖动/跑偏/不同步）；液压伺服/压力闭环；温控 PID；疑难故障定位；主导整机交付 |
| 资深（能扛事的） | 8 年+ | 整机电气方案架构、控制架构选型（总线/轴配置）、节拍优化、带团队、对接客户 |

**及格线看中级**：说不出多轴伺服调试、压力稳定性、温度均匀性的具体做法 → 大概率初级岗。

## 四、简历/JD 关键词

- **运动控制**：伺服、多轴、运动控制、EtherCAT、总线、电子凸轮、绝对定位、联轴
- **液压/压力（特别加分）**：液压伺服、伺服阀、比例阀、压力闭环、保压、压力曲线
- **温控**：PID、模具温控、热流道、温度曲线、温度均匀性
- **PLC/总线**：三菱（Q 系列）、西门子（S7-1200/1500）、基恩士、CC-Link、PROFINET
- **设备经验**：塑封机、模压机、传递成型、贴片机、键合机、固晶机、点胶机、分选机（**同家族可互相迁移**，池子不止塑封机厂）
- **加分**：真空塑封、IGBT/功率模块、MES、上位机（C#/LabVIEW）

## 五、面试验证（别问"你会伺服吗"——都会说会）

| 问法 | 真信号 | 假信号 |
|---|---|---|
| 合模压力怎么控制？电伺服还是液压？保压波动怎么解决？ | 聊得出伺服阀/压力闭环/PID 整定 | "师傅调的" |
| 整机几个伺服轴？什么总线？不同步怎么处理？ | 答得出轴数、EtherCAT/脉冲、排查法 | 含糊说不清 |
| 客户现场最难的一次调试？ | 讲到具体现象+排查（气泡/溢料/温不均/节拍） | 泛泛无细节 |

塑封机常见坑（听候选人讲这些就对味了）：**气泡→排气/压力曲线问题；溢料→合模压力问题；温度不均→温控问题；节拍上不去→时序优化问题**。

## 六、岗位价值（对候选人/对你）

- 半导体扩产 + 先进封装 + 车规功率模块（IGBT）需求大，塑封机跟着涨；
- **"电 + 运动控制 + 半导体背景"三者兼备的人稀缺**，好推，薪酬高于通用自动化设备同级别；
- 从塑封机可**平迁贴片机、键合机、分选机等封测设备**，职业路越走越宽。
