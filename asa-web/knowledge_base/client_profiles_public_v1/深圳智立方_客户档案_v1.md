# 客户档案：深圳智立方（深圳市智立方自动化设备股份有限公司，301312.SZ）——公开情报版 v1

> 来源：公开情报，2026-07-24 整理；内部客户手册暂无权限，拿到后合并。

## 1. 公司定位

- 自动化测试/组装设备上市公司（2022-07 创业板），2011 年成立，总部深圳宝安石岩；国家级专精特新"小巨人"，通过 AS9100D 航空航天质量认证（百度百科，2026-06）。
- 2025 年营收 6.07 亿元（+9.36%），归母净利 7538 万元（+26.71%），扣非净利 +59%；业务结构：消费电子 4.91 亿（80.9%）、**半导体 1.05 亿（17.3%，+48.96%）**（2025 年报，证券之星，2026-04-29）。
- 正从"苹果链自动化公司"向"半导体设备平台"转型——半导体是其第二增长曲线（年报口径，2026-04）。

## 2. 产品线（寻访时的技术关键词锚点）

- **光学检测/AOI**：Chip/Bar/晶圆/光模块 AOI，AI+传统算法结合，服务苹果、Meta、歌尔（AI 眼镜光波导检测）；
- **分选**：Mini/Micro LED 芯片分选机、CIS 分选机、全自动 IC 检测分选编带设备（WTR，用于 WLCSP/射频前端：滤波器、射频开关、PA）；2024 年芯片分选设备出货超 2000 台，客户含京东方华灿、兆驰、三安、乾照（投研通稿，2025-09）；
- **固晶/贴装**：高精度多芯片倒装贴片机 FC300（先进封装 Flip-Chip）、多芯片贴装固晶机 MDB20（存储/激光器/光通讯/CIS/MEMS/IGBT）；
- **光模块/激光芯片中道设备**：Bar 条摆排、拆巴、共晶机——切入光通讯封装（和光荟通稿，2025-08）；
- SEMICON CHINA 2026 主打"中后道全链条+先进封装贴装+射频前端分选"（中证报，2026-05）。

## 3. 人才信号（顾问最该看的部分）

- **招聘方向**（从业务反推+公开信息）：机器视觉算法、精密运控、机械设计、电气、软件（C++/C#）、光学系统、半导体工艺应用、海外销售/售后——半导体事业部扩张必然带动整机+应用工程师需求。
- **地域**：深圳宝安为主；客户现场分布华东/东南亚，海外拓展中（互动易，2026-07：正推进海外业务）。
- **薪酬带**：公开挂牌数据有限，待补；作为创业板上市公司有股权激励工具（具体期次待查公告）。
- 知识产权 366 项（专利 303），技术密度高（公司通稿，2025-06）。

## 4. 近期动态（动机与时机信号）

- 半导体业务收入一年翻倍（占比 12%→17.3%），公司明确"以半导体设备为核心增长方向"（2025 年报，2026-04）= **半导体团队扩编窗口**；
- AI 眼镜（Meta Ray-Ban、小米）光波导检测放量，现金流支撑转型；
- 2026-03/05 连续参展推先进封装贴装与射频分选新品 → 需要懂先进封装工艺的应用/产品经理补位。

## 5. 寻访角度（怎么用这份档案）

- **卖人给它**：人才池 = 赛腾股份、博众精工、快克智能、新益昌、凯格精机、德龙激光、大族系设备公司，以及 ASMPT/新益昌固晶产品线团队；机器视觉+精密运控+半导体工艺三重背景最对口；光模块设备方向可挖光迅/中际旭创/新易盛的设备与工艺工程团队。
- **从它那挖人**：其苹果链视觉检测工程师是 3C 自动化同行的通用硬通货；半导体事业部骨干短期内被股权绑定+业务高增长，挖动成本高，建议只定向接触非核心层。
- **推荐定制**：区分"3C 测试基因"与"半导体工艺基因"——推荐时强调候选人对半导体客户（而非果链）的交付经验；上市公司流程规范，注意背调与竞业条款审查。
