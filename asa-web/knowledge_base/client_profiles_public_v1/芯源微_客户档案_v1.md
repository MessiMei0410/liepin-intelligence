# 客户档案：芯源微（688037.SH）——公开情报版 v1

> 来源：公开新闻/券商研报/招聘平台，2026-07-24 整理；内部客户手册暂无权限，拿到后合并。
> 用途：寻访策略、推荐报告定制、判人评估器"动机信号"维度。

## 1. 公司定位

- 国内**涂胶显影（Track）设备唯一规模量产厂商**，国家 02 重大专项唯一涂胶显影设备承担单位；后道先进封装涂胶显影国内市占率第一，并切入前道清洗，定位"大湿法平台"（据新浪财经研报，2026-07）。
- 总部沈阳（浑南），2025 年 6 月北方华创完成股权收购成为控股股东（"A 吃 A"首例，据财新，2025-10），现为北方华创体系内湿法/Track 平台，董事长董博宇（据同花顺业绩说明会，2026-06）。
- 2025 年营收 19.48 亿元（+11.1%），归母净利 0.72 亿元（-64.6%，主因政府补助减少+新品毛利低）；2026Q1 营收 3.31 亿元（+20.08%）（据公司年报/东吴证券点评，2026-04/05）。**利润承压但订单与交付在放量**。

## 2. 产品线（寻访时的技术关键词锚点）

- **前道涂胶显影**：offline 已量产（上海华力、长江存储、中芯绍兴等客户），I-Line 小批量产，**KrF/ArF 在长江存储、中芯绍兴等验证中，ArFi 在研**——前道高端 Track 是当前技术攻坚核心（据东方财富研报库，2026-07）；
- **前道清洗**：Spin Scrubber 物理清洗国内市占率约 30%，**化学清洗机 2025–2026 放量**（申万/中邮研报，2026-04/07）；
- **后道先进封装**：涂胶显影+单片湿法，封装龙头客户批量重复订单；**临时键合/解键合设备**国产化推进中；
- **化合物/MEMS 等小尺寸设备**：基本盘业务；
- 北方华创协同：与刻蚀/薄膜/炉管做工艺整合，研发、供应链、客户资源共享（据财新，2025-10）。

## 3. 人才信号（顾问最该看的部分）

- **招聘主力方向**（结合产品攻坚推断+公开岗位）：Track 整机（机械/电气/软件/控制）、**湿法化学工艺**、流体/热工、光刻配套工艺应用工程师、客户现场（FSE/客服）——化学清洗与前道 Track 验证放量期，工艺与应用岗最缺；
- **地域**：沈阳本部（研发+制造）；客户现场岗分布上海/合肥/武汉/绍兴等 Fab 集中地；与北方华创（北京）整合后存在**沈阳↔北京双向调动/协同岗**；
- **薪酬带参考**：公开挂牌数据有限，待补；沈阳本地设备厂商薪酬低于京沪深同行 10–20% 是行业常识，但北上深驻厂岗会拉齐；
- **激励**：研发费用连续多年占营收 10% 以上（据业绩说明会，2026-06）；具体股权激励计划公开信息有限，待补；
- 猎头友好度：被北方华创控股后，HR 体系与招聘渠道处于切换/整合期，存在窗口。

## 4. 近期动态（动机与时机信号）

- **北方华创入主后的整合期**（2025-06 起）：组织架构、汇报线、激励体系调整，沈阳团队对"被并购"心态复杂——**整合观望期 = 挖人窗口**；同时北方华创体系资源注入，对候选人可讲"平台升级"故事；
- 前道 KrF/ArF Track 验证关键期 + 化学清洗放量 → 验证/工艺/应用工程师需求持续；
- 2025 年净利下滑 65%，若年终奖/调薪缩水，**骨干薪酬满意度下降是现实动因**（据年报，2026-04）；
- 长鑫 IPO、长江存储扩产 → 存储客户 Track/清洗订单景气（据雪球供应商梳理，2026-05）。

## 5. 寻访角度（怎么用这份档案）

- **同行对手/人才池**：Track 对标东京电子（TEL）——TEL 大连/上海团队、SCREEN 在华团队是顶级目标池；国内可挖盛美上海（清洗重叠）、至纯科技（湿法）、北方华创内部（整合敏感期反向流动）；
- **最缺岗位**：前道 Track 整机系统工程师、化学清洗工艺/应用、验证 Demo 工程师、资深 FSE；
- **卖人给它**：讲"国产 Track 独苗+前道高端突破的历史性窗口"+"北方华创平台资源背书"，对 TEL/SCREEN 背景候选人讲技术主导空间；对国产同行讲订单与验证资源；
- **从它那挖人**：整合期+利润下滑期，Track/清洗工艺与整机人才是全行业稀缺标的（拓荆、盛美、Fab 厂工艺整合岗都接得住）；
- **推荐定制**：突出候选人"设备+工艺"双重 knowhow（Track 是光刻配套，懂光刻胶/显影工艺者极稀缺）；整合期注意确认汇报线与工作地点（沈阳 vs 北京）。
