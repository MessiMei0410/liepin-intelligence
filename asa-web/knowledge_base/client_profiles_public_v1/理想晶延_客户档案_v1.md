# 客户档案：理想晶延（理想晶延半导体设备（上海）股份有限公司）——公开情报版 v1

> 来源：公开情报，2026-07-24 整理；内部客户手册暂无权限，拿到后合并。
> 用途：寻访策略、推荐报告定制、判人评估器"动机信号"维度。

## 1. 公司定位

- 以 **CVD（化学气相沉积）技术为核心**的光伏+半导体及泛半导体设备商，成立 2013-05，总部上海松江经开区，浙江海宁设全资子公司（来源：百度百科，2026-02-18）。
- 控股股东为**正泰集团**（直接+间接合计控制 41.761%），实控人南存辉，属"正泰系"（来源：新京报贝壳财经，2020-11-24）。
- 规模 100–499 人，注册资本约 5,735 万元，外商投资（未上市）股份公司；国家级专精特新小巨人（来源：看准网/innohere，2024）。
- 未上市。2020-07 曾备案科创板 IPO 辅导（国泰君安），**2021-09 辅导终止**，目前未见重启申报的公开信息（来源：启信宝企业公告，2021-09-17）。

## 2. 产品线（寻访时的技术关键词锚点）

- **光伏主线**：空间型板式 **ALD**（国产首台，用于 TOPCon 电池钝化，国内市占率最高时近 50%）、**PECVD、SALD**，覆盖 TOPCon/BC/钙钛矿电池技术；设备累计销量超 400 台（来源：百度百科，2026-02-18）。
- **半导体第二曲线**：多片装 ALD、CVD、**氧化退火设备**，团队含中韩日籍专业人员；2019 年并购新加坡 FA Systems Automation，进入**半导体封测装备**（来源：百度百科，2026-02-18）。
- 关键词：ALD/PECVD/CVD、真空镀膜、等离子体、TOPCon、氧化退火、封测自动化。

## 3. 人才信号（顾问最该看的部分）

- **招聘方向**：客服工程师（驻浙江海宁）、设备研发与工艺岗为主；看准网显示在招约 23 个岗位（2024-05 口径），社招为主、量不大。
- **地域**：上海松江（研发总部）+ 浙江海宁（制造/客服基地）——长三角异地候选人有落点。
- **薪酬带**：看准网员工评价口径"高于平均水平"，无具体挂牌带宽，**待补**；福利含五险一金、免费班车、餐补、补充医疗（来源：看准网，2024-05）。
- **激励**：正泰系控股+两轮外部融资（2020 A 轮浙民投/上海科创基金等；2023-01 B 轮龙鼎投资），IPO 终止后核心骨干的股权退出预期落空 = 潜在动因人群（来源：innohere 融资历史）。

## 4. 近期动态（动机与时机信号）

- IPO 辅导 2021-09 终止后无公开重启动作，叠加 2024 年以来**光伏行业产能过剩、电池厂资本开支收缩**，光伏设备商普遍承压——其半导体设备第二曲线的投入决心与资源分配值得面谈确认（待补）。
- 无近期大额融资/扩产公开新闻（2023 B 轮后无新轮次披露），公开信息偏静。

## 5. 寻访角度（怎么用这份档案）

- **卖人给它**：ALD/CVD/真空镀膜方向人才池 = 微导纳米、拉普拉斯、捷佳伟创、拓荆科技、北方华创薄膜事业部、应用材料/ASM 在华团队；光伏设备想转半导体赛道的人选是双向奔赴的最佳标的；封测自动化方向可看 FA Systems 同类（苏州/新加坡背景）。
- **从它那挖人**：光伏设备景气下行+IPO 终止，其 ALD 工艺与真空技术骨干对微导纳米、拉普拉斯、半导体薄膜设备厂均有溢价；海宁基地人员向上海/杭州迁移意愿通常较高。
- **推荐定制**：突出候选人"光伏镀膜设备↔半导体薄膜"跨赛道迁移能力；公司外资架构+正泰控股，风格偏工程师文化，稳定性诉求中等。
