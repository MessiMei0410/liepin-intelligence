# 客户档案：四方思锐智能（青岛思锐智能科技股份有限公司）——公开情报版 v1

> 来源：公开情报，2026-07-24 整理；内部客户手册暂无权限，拿到后合并。
> 注：公司曾用名"青岛四方思锐智能技术有限公司"，2025-02 股改后更名"青岛思锐智能科技股份有限公司"，寻访与判人时注意简历上的旧名。

## 1. 公司定位

- 半导体**前道工艺设备**商，2018-01 成立，总部青岛自贸片区，中车系背景（中车青岛四方所与中车国华合资发起）；国家级专精特新"小巨人"（36氪/百度百科，2026）。
- 双主业：**原子层沉积（ALD）设备 + 离子注入（IMP）设备**；2018 年全资收购 ALD 技术发源地芬兰 BENEQ，形成海外研发中心（36氪项目库，2018-01）。
- 融资至 C 轮：B 轮数亿元（2024-02，上汽/鼎晖/创新工场等）→ B+ 轮（2024-05）→ C 轮数亿元（2025-11/12，国开制造业转型基金、国调基金领投）；B+ 轮后估值 41 亿元（铅笔道/OFweek，2025-02）。**2026-02 完成科创板 IPO 辅导备案，计划 2026 年申报**（百度百科，2026-06）。
- 规模口径注意：百度百科同时出现"员工近 500 人"与"研发团队超 500 人"两种说法，待核；硕博占比超 50%。

## 2. 产品线（寻访时的技术关键词锚点）

- **ALD**：Transform 系列量产型（热法+等离子体），用于 IC、SiC/GaN 三代半、新能源电池、光学镀膜；英诺赛科 8 英寸 GaN 产线采购订单（化合物半导体网，2026-04）；
- **离子注入**：8MeV 高能注入机 2023-09 首台交付（填补国内空白，38 吨级，用于 CIS/5G 射频），2024 年完成中高低能量全谱系机型（百度百科，2026）；
- 应用：逻辑、存储、功率、CIS、5G 射频；全球 40 国 500+ 客户。

## 3. 人才信号（顾问最该看的部分）

- **招聘方向**：薄膜工艺研发、真空机械、自动化/电气、软件、离子源/束线物理、售后/应用工程师（智联/猎聘在招，2026-02）；校招岗位以薄膜工艺、真空机械、自动化研发为主（百度百科校招记录）。
- **地域**：青岛（总部+制造中心）、北京、上海研发中心、芬兰研发中心——四地布局对北方/长三角候选人都有落点。
- **薪酬带**：公开挂牌数据有限，待补；设有国家级博士后科研工作站（2025）。
- **激励**：IPO 前夜，C 轮后通常伴随员工持股平台扩容——**具体 ESOP 范围待补，这既是卖点也是判人要点**。

## 4. 近期动态（动机与时机信号）

- 2025-06 半导体先进装备研发制造中心在青岛投产（占地 95 亩、计划投资超 12 亿元）→ 产能爬坡，装配/工艺/交付岗放量；
- IPO 申报期（2026）：规范期招聘放量 + 关键岗位（质量、体系、财务）补人；
- 全谱系离子注入机刚完成研发 → 从研发转量产，最缺整机交付与客户端工艺支持人才。

## 5. 寻访角度（怎么用这份档案）

- **卖人给它**：ALD 方向人才池 = 北方华创、拓荆科技、微导纳米、江苏首芯、ASM/东京电子/Lam 在华团队；**离子注入方向国内极稀缺**，池子 = 凯世通（先导基电）、中科信、烁科晶体，以及 Axcelis/应用材料/住友/SEN 在华服务与研发团队——高价挖角主战场。
- **从它那挖人**：IPO 锁定期临近，早期核心员工短期难动；但其芬兰 BENEQ 团队背景的应用工程师、以及 ALD 工艺人才对拓荆/微导有吸引力，反向防挖是它的痛点（可借此切入谈 RPO）。
- **推荐定制**：强调候选人"真空系统+等离子体+工艺"复合背景；离子注入候选人必查束线/离子源实操与客户端装机记录；青岛地域需前置沟通安家方案。
