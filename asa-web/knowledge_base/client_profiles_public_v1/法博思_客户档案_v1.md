# 客户档案：法博思（法博思（宁波）半导体设备有限公司）——公开情报版 v1

> 来源：公开情报，2026-07-24 整理；内部客户手册暂无权限，拿到后合并。
> 用途：寻访策略、推荐报告定制、候选人动机判断。

## 1. 公司定位

- 半导体**量测/检测设备**初创：为晶圆厂提供国产化、自主可控的量测设备，定位几何形貌测量 + 缺陷检测细分（36氪，2023-08-30）。
- 2019 年成立，总部宁波余姚，**上海设研发中心**（公司官网；企查查，2023）。
- 小团队：2023 年报道时 20 余人、研发占比约 80%；创始人/CEO 宋金龙（夏普中国研发中心、联想研究院背景，3D 算法/视觉检测测量方向），COO 朱建国（海尔集成电路、贝岭、英国 Plessy 出身）（36氪，2023-08-30）。
- 融资：2023 年 9 月完成数千万元 A 轮，投资方为合肥敦勤致元、兴牛资本（Intel/ARM 高管创立）（36氪/集微网，2023-09）。

## 2. 产品线（寻访时的技术关键词锚点）

- **衬底片检测设备**：大硅片及三代半衬底的几何形貌（warp/bow/TTV 类）+ 缺陷检测，代表机型 PRF300（36氪，2023-08）。
- **晶圆级先进封装检测设备**：2D/3D 缺陷检测、粗糙度、TSV 轮廓、OVERLAY 与 CD 检测（36氪，2023-08）。
- 客户验证里程碑（官网发展历程）：**多层测厚设备进入长电科技；形貌设备进入中芯国际、华为、新昇**（fabxlab.com 官网，2024-2025）；更早报道口径为已出货覆盖中芯国际、长电、日月光等 12 寸客户（36氪，2023-08）。
- 关键词：白光干涉/3D 形貌、TSV 轮廓量测、overlay/CD、机器视觉、3D 算法、零部件国产化。

## 3. 人才信号（顾问最该看的部分）

- **招聘方向（推断）**：3D 视觉算法、光学系统设计、精密机械/运动控制、应用工程师（与客户共研工艺是该公司文化，36氪 2023-08）；具体在招岗位与薪酬带公开信息有限，待补。
- **地域**：宁波余姚（总部/制造）+ 上海（研发中心）——上海端可直接对接张江量检测人才圈。
- **激励**：A 轮阶段，期权空间大概率存在但未公开，待补。
- 团队极小 = 单人职责宽、培养体系弱，候选人动机多落在"大厂平台/稳定性"对比上。

## 4. 近期动态（动机与时机信号）

- 官网历程显示 2024-2025 年产品连续进入长电、中芯、华为、新昇 → 从 DEMO 走向量产客户，应用/售后/现场工程师缺口放大。
- A 轮资金用途即"研发团队扩展+DEMO 机台生产+新品研发"（36氪，2023-08），缺陷检测新品类扩张中 → 光学检测方向有新增 headcount 的逻辑。
- 2023 年后未见新融资公开披露，下一轮融资节奏待跟踪（资金面的紧松直接影响招聘窗口）。

## 5. 寻访角度（怎么用这份档案）

- **卖人给它**：目标池 = 中科飞测、上海睿励、精测电子半导体事业部、天准科技、东方晶源、御微、微崇（同赛道中小厂互挖）；KLA/Onto/Hitachi High-Tech 在华应用与研发工程师。卖点：创始团队技术背景纯正（夏普系 3D 视觉）、客户名单硬（中芯/长电/华为/新昇）、余姚+上海双点、早期股权。
- **从它那挖人**：20 余人团队每位研发骨干都是"3D 形貌+先进封装检测"稀缺复合背景，对中科飞测/精测/天准是精准补给；挖角动机 = 小厂平台风险、宁波地域、薪酬天花板。注意创始人稳定性强，优先触达非创始层。
- **推荐定制**：它家文化强调"与客户共研工艺、把单品做细做精再横向扩"（36氪，2023-08），推荐时突出候选人客户现场 problem-solving 案例与零部件国产化/降本经验，而非纯论文型背景。
