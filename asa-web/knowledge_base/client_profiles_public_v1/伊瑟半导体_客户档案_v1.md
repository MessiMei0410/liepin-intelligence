# 客户档案：伊瑟半导体（伊瑟半导体科技（江苏）股份有限公司）——公开情报版 v1

> 来源：公开情报，2026-07-24 整理；内部客户手册暂无权限，拿到后合并。
> ⚠️ 本公司公开信息量少，多依赖官网/早期招聘页，建议合作后尽快以内部资料校准。

## 1. 公司定位

- 封测设备商，2021-02 成立（猎聘工商数据，2021-12），位于无锡市锡山区云林科创中心，法定代表人徐庆章。
- 注册资本口径不一：官网及拉勾简介称 1.2 亿元（官网，2026-04），猎聘工商快照显示 6000 万元（2021-12）——并列待核。
- 聚焦**功率半导体封装设备 + CIS 封装设备**；自称与富士通、士兰微、英飞凌达成战略合作，客户含华润、华天科技、中天科技、通富微电（锡山区政府调研通稿，2023-05；口径为公司自述，未独立验证）。
- 落户当年（2021）开票 1.5 亿元，官方预计 2021–2023 累计开票不低于 6 亿元，曾提"五年内启动 IPO"（搜狐/锡山经开区通稿，2021-11）——后续进度无公开更新，待核。

## 2. 产品线（寻访时的技术关键词锚点）

- **功率半导体贴片装备**：全自动高精度软焊料贴片机，面向功率模块封装（官网产品页）；
- **CIS 设备**：高端焊线机、精密烤炉/固化炉，用于 CMOS 图像传感器（安防/手机）；
- **定制化全自动封装产线**：基于 GaN/SiC 封装工艺积累的整线集成；
- 合作/代理线索：官网展示新川（Shinkawa）、山田（Yamada）产品；**2026-04 YAMAHA 日方社长一行到访考察深入合作**（官网新闻，2026-04）——疑似设备代理/技术合作，是理解其技术路线的重要线索。

## 3. 人才信号（顾问最该看的部分）

- **招聘方向**（猎聘，2021-12 快照，数据偏旧）：装配工艺工程师 8–12K·13 薪、电气工程师 8–12K·13 薪、机械/电气装配 6–9K、装配主管 10–15K、嵌入式软件 5–8K——以**装配/电气/工艺的中端执行岗**为主，研发高端岗未见大量挂牌。
- **地域**：无锡锡山为主，深圳设服务据点。
- **团队基因**：多为国内知名大学与台湾知名大学硕士（拉勾简介）——台系封测背景是其技术底色。
- 薪酬带整体偏中端（见上），高端研发薪酬无公开数据，待补。

## 4. 近期动态（动机与时机信号）

- 2024-07 获无锡市企业技术中心认定（锡山工信公示，2024-07）；
- 2026-04 与 YAMAHA 高层互访，合作深化信号；
- 功率半导体（SiC/GaN 模块）扩产周期内，贴片/烧结/键合类设备需求景气，但**该公司近两年无融资、无大项目公开新闻，活跃度存疑，待客户侧核实**。

## 5. 寻访角度（怎么用这份档案）

- **卖人给它**：人才池 = ASMPT、K&S、新川/Shinkawa、BESI（贴片/焊线产品线在华团队），国内 = 快克智能、新益昌、凯格精机、触点智能（同在贴片/固晶赛道）；功率模块封装工艺经验是硬通货。
- **从它那挖人**：体量小、IPO 进度不明，若经营承压，其士兰微/英飞凌项目经验的应用工程师对同行有吸引力——可作为被动候选池监测。
- **推荐定制**：先确认对方到底要"研发型"还是"装配交付型"——从挂牌看后者居多；推荐功率封装候选人时突出 SiC/GaN 模块贴装、烧结、键合的产线实操。
- **风险提示**：公司体量小、公开信息少，合作前建议先核实付款能力与真实招聘需求（防止"挂着不招"）。
