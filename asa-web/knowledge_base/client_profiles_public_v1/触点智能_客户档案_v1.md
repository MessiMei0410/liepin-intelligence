# 客户档案：触点智能（东莞触点智能装备有限公司，APIE）——公开情报版 v1

> 来源：公开情报，2026-07-24 整理；内部客户手册暂无权限，拿到后合并。
> 用途：寻访策略、推荐报告定制、判人评估器"动机信号"维度。

## 1. 公司定位

- 先进封装设备商，2016-12 成立于东莞松山湖，国家级专精特新"小巨人"；主业为晶圆级热压键合机（TCB）、混合键合机（HB）、固晶/贴片设备，设备用于 HBM、高性能 CPU/GPU、AI 芯片 2.5D/3D 封装（公司官网"关于我们"，2024-05）。
- 融资密集：B 轮舜宇光学（2022-06）→ B+ 轮华天科技/中金资本（2024-02）→ C 轮湖北集成电路产业投资基金/中信证券投资等（2025-03）→ C+ 轮东莞投控/超越摩尔（2025-12）→ D 轮国晨创投/大米创投（2026-04）（36氪项目库，2026-04）。股东里华天科技、舜宇、欧菲光、传音均为产业方 = 股东即客户。
- 员工 100–499 人，专利 71+（innoHere，2024）；研发人员占比 56%，本硕博 85%（校招简章，2025-09）。

## 2. 产品线（寻访时的技术关键词锚点）

- **固晶/贴片**：CMOS 固晶机（中国首家量产）、存储超薄多层叠 Die 固晶机（国内首家量产，对标 HBM 堆叠）、通用 MCM 贴装机（校招简章/知乎 GMIF，2023-09）；
- **先进封装键合**：晶圆级 TCB 热压键合（"打破国产空白"，公司口径）、HB 混合键合——HBM/2.5D/3D 关键词；
- **CIS 封装**：COB 整线方案（首家规模化量产），客户围绕摄像模组/IR 滤光/镜头；
- 底层技术栈：运控驱动、精密机械、热固流仿真、光学图像/3D 机器视觉、微纳电机、工业软件。

## 3. 人才信号（顾问最该看的部分）

- **招聘方向**：校招主力 = 机械、软件（C++/QT）、视觉、电气、工艺、售后、仿真、项目（2027 届秋招，应届生网 2025-10）；社招核心 = 工艺工程师、销售、QT 软件（猎聘在招）。
- **地域**：东莞松山湖为主；东京、新加坡、香港、深圳、成都设研发分部——海外/异地候选人有落点。
- **薪酬带**：校招本科 8–15K、硕士 12–20K（校招简章 2025-04/2025-09）；社招工艺 15–30K、销售经理/总监 20–35K（官网"加入触点"，2025-06）。大小周、12 薪+绩效 1–2 个月、提供住宿。
- **团队基因**：核心团队来自 ASMPT、BESI、K&S、新川/Shinkawa、日立、雅马哈、TDK、基恩士（校招简章，2025-09）——挖人方向与它的血脉一致。

## 4. 近期动态（动机与时机信号）

- 一年内连拿 C/C+/D 三轮（2025-03→2026-04），弹药充足 = 扩张期招聘窗口；
- HBM/AI 封装景气 → TCB/HB 国产对标 BESI/ASMPT，处于"从样机到批量验证"关键期，交付与应用工程师需求大；
- 海外分支扩张（新加坡/马来西亚/美国/奥地利服务团队，官网）→ 需要英语售后/海外交付。

## 5. 寻访角度（怎么用这份档案）

- **卖人给它**：人才池 = ASMPT、BESI、K&S、新川（中国/新加坡团队）、国内快克智能、新益昌、凯格精机、华封科技；有 TCB/HB 或存储固晶经验的整机+工艺复合人才最稀缺。
- **从它那挖人**：其固晶/贴装应用工程师在 OSAT 与模组厂受欢迎；D 轮后若启动 IPO，早期未持股骨干有套现焦虑窗口。
- **推荐定制**：突出候选人"精密运控+机器视觉+封装工艺"三合一经历；它家大小周+现场调试强度大，推荐时确认候选人对驻场/加班的接受度。
