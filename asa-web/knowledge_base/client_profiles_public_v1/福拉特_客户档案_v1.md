## 1. 公司定位

- **半导体&显示湿法工艺制程装备一站式供应商**，工商成立 2019-03（团队自述始于 2011 年），注册地南京经济技术开发区红枫科技园，法定代表人李素华，注册资本约 1,184–1,286 万元（不同时点工商口径）（来源：猎聘企业页；亿欧数据，2026-06-05）。
- 规模约 100–150 人（亿欧口径 105 人；招聘平台 100–499 人档）；省级专精特新、国家高新技术企业（来源：亿欧/innohere）。
- 单片与槽式湿法设备规格达 19nm（公司/投资方口径，待验证），自述"国内首创技术 8 项、国产独家 3 项、全球首创 3 项"（来源：南京市创投集团官网，2026-06-05）。
- 融资：2025-04 Pre-A 轮数千万元（南京市创投集团、新港高投、东方产融）；2026-06 A 轮（翌昕投资、东大资本）（来源：36氪/亿欧数据）。

## 2. 产品线（寻访时的技术关键词锚点）

- **单片湿法设备**：single 清洗、湿法刻蚀、去胶剥离；**槽式湿法设备**：槽式刻蚀清洗机、槽式去胶机、蒸镀 Mask 清洗机（来源：公司官网 flatae.com，2025-11）。
- **配套与定制**：涂胶、显影、药液浓度在线检测系统（应用广泛）、高精度磨边机（Micro LED/硅片/LCD）、贴合、CCD 视觉检测、**EFEM**（来源：猎聘公司简介）。
- 下游：半导体 + 显示（LCD/AMOLED/Micro LED/Micro OLED）双赛道，"软硬件一体化"是其差异化卖点。
- 关键词：Wet Process、single/bench、药液管理、EFEM、显影涂胶。

## 3. 人才信号（顾问最该看的部分）

- **招聘方向**：机械设计（SolidWorks/UG/Creo）、电控设计工程师、装配调试、视觉软件——典型中小型整机厂配置（来源：应届生网/猎聘在招岗，2026-07）。
- **地域**：南京（栖霞/经开区）为主；客户现场出差/驻厂（半导体显示大厂基地）。
- **薪酬带参考**：电控设计工程师 6–13k·13 薪、本科 5 年经验（猎聘挂牌，2026-07-18）——**薪酬明显低于上海同行**，是反向挖人的有利条件，也是卖人时的压价风险点。
- **激励**：两轮融资刚到位，未见股权激励公开信息，**待补**。

## 4. 近期动态（动机与时机信号）

- 2026-06 获半导体显示大厂**数千万元订单**：30+ 台主制程设备、19 种机型，入驻客户百亿级新型显示芯片产业基地（来源：南京市创投集团官网，2026-06-05）——订单放量 → 交付/装配/调试/售后工程师短期紧缺。
- 2026-06 完成 A 轮融资，产能与人员扩张窗口期。

## 5. 寻访角度（怎么用这份档案）

- **卖人给它**：湿法设备同行池 = 至纯科技、盛美上海、芯源微、亚电科技、苏州智程；显示设备池 = 联得装备、易天股份；EFEM/自动化岗可看机器人/传输类厂商。卖点：湿法+显示双赛道订单在手、A 轮资金到位、南京生活成本低——适合上海/苏州湿法工程师回流或降本选择。
- **从它那挖人**：其薪酬带偏低，湿法工艺/机械/电控工程师对上海同行（盛美、至纯）溢价空间 30%+，是优质"性价比人才池"；订单高峰期交付岗压力大，动因可用"薪酬倒挂+平台升级"撬动。
- **推荐定制**：突出候选人 wet bench/single 机型的量产交付与客户端装机经验；它家非标定制多，需强调候选人"从图纸到调试"的全程独立交付能力。
