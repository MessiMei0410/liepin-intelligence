# 客户档案：天成先进（珠海天成先进半导体科技有限公司，NAST）——公开情报版 v1

> 来源：公开情报，2026-07-24 整理；内部客户手册暂无权限，拿到后合并。

## 1. 公司定位

- **12 英寸晶圆级 TSV 立体集成（先进封装）制造基地**，2023-04 成立，注册资本 9.5 亿元，位于珠海高新区唐家湾，央企控股（百度百科，2025-12）。
- 股东：西安微电子技术研究所（航天九院，董事长唐磊任所长）、中兴新通讯、珠海格力集团旗下基金（品牌发布会通稿，2024-03）——**航天+中兴+珠海国资**，珠海市"立柱项目"。
- 2024-12-30 产线正式投产（珠海特区报，2024-12-31）；一期达产年产 24 万片 TSV 立体集成产品，二期规划 60 万片，人员规划超 1200 人（校招简章，2024/2025 届）。

## 2. 产品线（寻访时的技术关键词锚点）

- **3D/2.5D-TSV**、**2.5D-Fanout**、**UHD-FCBGA**、3D-WLCSP、Bumping 晶圆级封装（官网/企查查口径，2026）；
- 自有"九重"晶圆级三维集成技术体系：纵横（2.5D）、洞天（3D）、方圆（MicroAssembly）（投产通稿，2024-12）；
- 工艺关键词（从招聘与设备清单反推）：**深硅刻蚀（Dry Etch）、激光钻孔、键合、减薄、RDL、电镀、SMT/微组装**（智联在招岗位，2026-01；节能审查文件，2023-12）；
- 应用：AI/高算力、存算一体、5G、自动驾驶、传感成像、射频通信。

## 3. 人才信号（顾问最该看的部分）

- **招聘方向**：工艺工程师（刻蚀/激光钻孔/键合/电镀/RDL 等模块）、设备工程师、设计工程师、仿真、产品/NPI、测试、失效分析、厂务、特气——典型**新 Fab 爬坡期全谱系招聘**（2025 届春招简章，2025-03；智联在招 2026-01）。
- **地域**：珠海单点；对长三角/西安封装人才属异地引进。
- **薪酬带**：校招本科 6–10K、硕士 10–16K（2024 届简章）；社招工艺工程师 10–30K，本科均值约 23K、3–5 年约 17.5K（职友集挂牌统计，2024-12）——社招中高端岗可到 20–30K 档。
- **福利**：五险二金、年终奖、提供住宿、用餐补贴（校招简章）——国资封装厂标准包。

## 4. 近期动态（动机与时机信号）

- 2024-12 通线投产 → **当前处于产能爬坡+客户验证期，工艺/良率/NPI 岗位持续缺人**；
- 从封顶（210 天）到投产的"天成速度"说明集团强压进度，交付文化浓；
- 先进封装（TSV/2.5D/3D）是 AI 芯片国产化热点赛道，珠海给足政策，二期 60 万片规划 = 中长期扩编确定性。

## 5. 寻访角度（怎么用这份档案）

- **卖人给它**：核心人才池 = 长电科技、通富微电、华天科技、甬矽、晶方半导体、华进半导体（TSV 中试线）、盛合晶微；TSV 深硅刻蚀/键合/减薄/RDL 工艺工程师最紧缺；设备岗可从应用材料、Lam、EVG、DISCO 服务商及二手设备商处挖。
- **从它那挖人**：暂不宜主攻——新厂员工多带"建仓"心态；但航天体系管理风格+珠海地域，若爬坡不及预期，2027 年后可能出现工艺骨干流动。
- **推荐定制**：突出候选人**12 英寸产线量产经验**（它设备以国产为主，有国产设备调试经验者加分）；珠海地域顾虑（配偶、子女、房价虽友好但圈子小）需前置沟通；国资流程长，推荐周期按 4–8 周管理候选人预期。
