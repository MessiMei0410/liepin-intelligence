# 客户档案：联讯仪器（苏州联讯仪器股份有限公司，688808.SH）——公开情报版 v1

> 来源：公开情报，2026-07-24 整理；内部客户手册暂无权限，拿到后合并。

## 1. 公司定位

- 高端测试仪器设备商，2017-03 成立于苏州高新区，由光通信与半导体测试领域专家团队创办；已上市（科创板 688808，爱企查 2026-07）。
- 双主业：**电子测量仪器 + 半导体测试设备**。2025 年营收 11.94 亿元（半导体测试设备 5.57 亿占 46.7%、电子测量仪器 5.46 亿占 45.7%），归母净利 1.74 亿元（百度百科援引年报，2026-06）。
- 市场地位：2024 年中国光通信测试仪器市占 9.9%、排名第三（前五中唯一本土企业）；中国光电子器件测试设备市场、SiC 功率器件晶圆级老化系统市场均排名第一（Frost & Sullivan，转引自百度百科，2026-06）。

## 2. 产品线（寻访时的技术关键词锚点）

- **光通信/高速测试**：宽带采样示波器（50GHz，含自研采样芯片）、高速误码仪、时钟恢复、波长计——客户为中际旭创、新易盛、光迅、Lumentum、Coherent、Broadcom（官网/招股书口径，2026）；
- **电性能**：高精度源表（SMU）、半导体参数分析仪 SA8000、低漏电开关矩阵、WAT 晶圆参数测试；
- **光芯片测试**：激光器 CoC/裸 Die 老化（BI6201/6202/6203）、硅光晶圆测试机 SCT9001；
- **功率芯片测试**：SiC 晶圆级老化（车规）、KGD 裸芯片分选测试、AL6200 Die 级目检分选；
- **新品线**：DRAM/HBM 存储测试（CP/FT、老化）、3.2T 光模块测试、车规芯片测试、实时示波器/任意波形发生器（百度百科研发方向，2026-06）。

## 3. 人才信号（顾问最该看的部分）

- **招聘方向**：高速信号处理（射频/高速硬件）、微弱信号处理、超精密运控、FPGA/嵌入式、测试软件、应用工程师；研发人员占比 40%+，研发投入占比 24%+（官网/招股书口径，2025-09）。
- **地域**：苏州总部；**武汉东湖高新区在建存储测试设备研发基地**（百度百科，2026）——武汉是存储测试人才蓄水池（长存生态），异地招聘落点明确。
- **薪酬带**：公开挂牌数据有限，待补；作为已上市科创板公司，预期有股权激励池，具体范围待补。

## 4. 近期动态（动机与时机信号）

- 科创板上市后进入扩张期：2026 年在苏州高新区投建研发中心+制造中心（规划年产 5000 台套）（百度百科，2026）；
- **存储测试（DRAM/HBM）是新战场**——从零建产品线，最缺 ATE/存储测试架构人才；
- AI 光模块（800G→1.6T→3.2T）景气拉动主业订单，交付与研发双扩张。

## 5. 寻访角度（怎么用这份档案）

- **卖人给它**：仪器侧人才池 = 是德科技、泰克、力科、普源精电、鼎阳科技；测试设备侧 = 爱德万、泰瑞达、长川科技、华峰测控、联动科技；光器件测试 = 光迅/中际旭创/新易盛内部测试工程团队。存储测试方向直接挖长川/爱德万/泰瑞达存储 ATE 团队。
- **从它那挖人**：上市后第一年部分老员工解禁/套现观望期；其光通信测试工程师是稀缺标的（旭创、新易盛也会反向挖）。
- **推荐定制**：突出候选人"高速信号完整性+测试算法+仪器整机"复合经历；对存储方向候选人，强调 DRAM/NAND 测试程序开发与量产导入经验。
