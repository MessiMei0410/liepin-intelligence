# 客户档案：奥特维（无锡奥特维科技股份有限公司，688516.SH）——公开情报版 v1

> 来源：公开情报，2026-07-24 整理；内部客户手册暂无权限，拿到后合并。
> 用途：寻访策略、推荐报告定制、候选人动机判断。
> ⚠️ 主业为光伏设备（串焊机龙头），本档案聚焦其**半导体封测设备业务线**。

## 1. 公司定位

- 科创板上市高端装备平台：光伏（串焊机全球龙头）、锂电/储能、**半导体封测设备**三线布局（公司问询函回复，2023）。
- 半导体是其明确的"第二曲线"：2025H1 半导体设备收入 0.72 亿元、同比 +726.63%（基数小）；2025 年 1-6 月半导体设备新签订单突破 9000 万元（2024 年全年破 1 亿元）（光大证券中报点评，2025-08-27）。
- 集团财务背景：2025H1 营收 33.79 亿（-23.5%）、归母净利 3.08 亿（-60%），光伏下行拖累明显；2025 年全年光伏设备订单处历史低位（财联社，2026-02-03）→ 资源向半导体/储能倾斜的动机强。

## 2. 产品线（寻访时的技术关键词锚点）

- **焊线（已量产）**：铝线键合机、IGBT 键合机——持续获气派科技、仁懋电子、应用光电（AAOI）等批量订单（光大证券，2025-08）；在研：金铜线键合机、倒装芯片键合机（问询函回复，2023）。
- **装片/划片**：晶圆划片机、装片机已在客户端验证（2025H1 口径，上证报，2025-08-26）；另投资立朵科技布局划片机（2023）。
- **AOI 检测**：传统封装 AOI + 先进封装 AOI（募投研发）+ 光模块 AOI（光通信场景，已获海内外批量订单）（公司调研纪要，2026-02-03）。
- 关键词：引线键合 wire bonding、铝线/铜线键合、die bonding 装片、精密点胶、多轴联动、焊头力控、AOI 光学检测。

## 3. 人才信号（顾问最该看的部分）

- **招聘方向（推断+披露）**：键合机研发（机械/运动控制/机器视觉）、AOI 算法与光学、装片机整机（披露时点装片机研发 24 人、87.5% 本科以上）（问询函回复，2023）；半导体业务生产人员约 50 人（2023-03 口径）→ 现在大概率已扩。
- **地域**：无锡（总部及半导体业务主体）；海外拓展中（产品销往 40+ 国）→ 海外售后/应用岗可能新增。
- **薪酬带/激励**：上市公司平台，有股权激励历史（光伏高峰期多期激励）；具体半导体线薪酬带公开信息有限，待补。
- 猎头友好度：上市公司多渠道招聘成熟；半导体线处于"扩军"期，对外部成熟键合机人才需求刚性。

## 4. 近期动态（动机与时机信号）

- 2025-08 中报：半导体收入/订单高增 vs 光伏大幅下滑 → 半导体线是公司内部"明星业务"，编制与预算倾斜（光大证券，2025-08-27）。
- 2026-02 披露：铝线键合机、AOI 已获批量订单，光模块 AOI 成新增长点（财联社，2026-02-03）。
- 光伏订单历史低位 → 集团内部人员向半导体线转岗/外部招聘并行，**也是从光伏线挖人去做半导体业务竞对的窗口**。

## 5. 寻访角度（怎么用这份档案）

- **卖人给它**：键合机目标池 = K&S（库力索法）、ASMPT、Besi 在华研发/应用团队，国产对标新益昌、大族封测、凯格精机、快克智能；AOI 目标池 = 康代/Camtek、奥宝、天准、精测。卖点：上市公司稳定性+半导体线高增速（订单年翻倍）、光伏现金流养活新业务、无锡区位。
- **从它那挖人**：其铝线键合机团队是国产 wire bonder 稀缺成建制力量，对键合设备同行与 OSAT（长电/通富/华天）设备部门均是优质池；挖角动机 = 光伏主业下行的心理影响、半导体线激励向集团口径看齐可能的落差。
- **推荐定制**：它家打法是"把光伏自动化的高速高精度运动控制/视觉能力平移到封测设备"，推荐时突出候选人高速运动平台、视觉对位、力控工艺经验；OSAT 客户现场经验（气派、仁懋类功率封测客户）是硬加分。
