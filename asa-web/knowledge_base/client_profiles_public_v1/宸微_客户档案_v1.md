# 客户档案：宸微（宸微设备科技（苏州）有限公司）——公开情报版 v1

> 来源：公开情报，2026-07-24 整理；内部客户手册暂无权限，拿到后合并。
> 用途：寻访策略、推荐报告定制、候选人动机判断。

## 1. 公司定位

- **迈为股份（300751.SZ）控股子公司**（法定代表人周剑，即迈为董事长），2022 年 10-12 月成立，承载迈为向**半导体前道核心装备**拓展的战略使命（BOSS 直聘公司页，2025-08；CSDN 行业文，2026-03）。
- 注册资本约 3158 万元；苏州吴江（迈为园区内，7000 平洁净实验室+8000 平办公楼及厂房）+ 上海浦东北蔡（1800 平独栋+万级洁净实验室）双点（BOSS 直聘，2025-08）。
- 体量：2023 年底研发设计与技术团队预计超 150 人（BOSS 直聘公司介绍）；专利已积累 70-96 条（天眼查各时点口径，2025-08 至 2026-06）。
- 迈为背书：光伏丝网印刷线全球龙头、显示（OLED/MLED 激光）装备商，底层能力为真空、激光、精密装备三大平台。

## 2. 产品线（寻访时的技术关键词锚点）

- 官方口径："主要产品覆盖**半导体生产前道领域**的智能化高端装备"（BOSS 直聘，2025-08），具体机型未公开。
- 从公开专利推断方向：**薄膜沉积（CVD/ALD 类）**——前驱体气路、混气底座、波纹管防沉积、薄膜制备与原位刻蚀；**刻蚀**——介质窗温控、电感线圈射频耦合、等离子体均匀性；**腔体/传输**——晶圆传输腔室降温、隔离阀、开盖结构（各专利新闻，2025-08 至 2026-06）。
- 2026-03 公告拟投 **15 亿元**在吴江建"半导体装备研发制造项目"，聚焦半导体生产智能化高端装备研发制造销售（迈为股份公告 via 智通财经，2026-03-06）。
- 关键词：CVD/ALD、前驱体输运、刻蚀腔体、ICP/射频耦合、温控均匀性、真空密封、晶圆传输。

## 3. 人才信号（顾问最该看的部分）

- **招聘方向**：半导体设备工程师（机械设计、电气研制、软件开发、精密制造一体）（BOSS 直聘，2025-08）；技术文档工程师等支持岗亦有（8-13k×13 薪，参考职级偏低，CSDN 招聘信息，2025-07）。
- **地域**：苏州吴江 + 上海浦东双点——可承接上海（张江/临港）前道设备人才外溢。
- **薪酬带**：公开信息有限，待补；参考迈为集团口径（上市公司+苏州区位）。
- **激励**：控股子公司架构，15 亿投资项目落地 → 大概率有子公司层面激励安排（未公开，待补）；迈为平台本身有上市公司激励历史。

## 4. 近期动态（动机与时机信号）

- 2026-03 拟投 15 亿元新建半导体装备研发制造项目（智通财经，2026-03-06）→ **明确的扩编信号**，研发+制造+销售全链都要人。
- 2025-2026 专利密集公开（气路/温控/刻蚀/传输）→ 产品处于工程化攻坚期，DEMO/验证阶段临近，应用与客服岗将前置储备。
- 迈为光伏主业同样面临行业下行，集团资源向半导体倾斜的动机强（类比奥特维逻辑）。

## 5. 寻访角度（怎么用这份档案）

- **卖人给它**：目标池 = 北方华创、中微、拓荆（CVD/ALD/刻蚀整机）、盛美、芯源微，及 AMAT/Lam/TEL 在华团队；精密制造/供应链岗可挖迈为体系外的光伏设备熟手。卖点：上市公司资源+初创成长空间（"站在巨人肩膀上的特种兵"）、15 亿投资背书、苏州+上海双办公、洁净实验室硬件到位。
- **从它那挖人**：成立仅 3 年多、产品未公开量产，若 2026-2027 DEMO 验证不及预期会出现第一波骨干松动；其团队（推测有北方华创/中微系成建制挖角背景）本身即是全行业前道设备人才池。当前阶段挖角难度中高（新项目刚注资，士气与期权预期在高位）。
- **推荐定制**：迈为系文化重"工程化落地+快速迭代"，推荐时突出候选人从图纸到量产的全周期经历与交付速度；CVD/ALD/刻蚀方向需细化到腔体级子系统经验（气路/温控/射频/传输），整机泛泛背景不讨巧。
