# 客户档案：邑文（无锡邑文微电子科技股份有限公司，邑文科技/AMTE）——公开情报版 v1

> 来源：公开情报，2026-07-24 整理；内部客户手册暂无权限，拿到后合并。

## 1. 公司定位

- 半导体**前道工艺设备**商，2011-03 成立，总部无锡新吴区；从二手设备翻新起家，2019 年首台自研等离子去胶机交付，2021 年完成向自研设备转型（南大校友会稿，2024-09；东方财富，2024-02）。
- 聚焦**特色工艺：SiC/GaN/GaAs 化合物半导体 + MEMS，以 8 英寸及以下市场为主**（官网/董事长受访口径，2022-09）。
- 资本化路径清晰：2022 年比亚迪入股并成最大外部股东（全面战略合作）；2024-02 启动 IPO 辅导（海通证券）；2024 年完成超 5 亿元 D 轮（中金佳泰、海通新能源领投）（艾邦/万创投行，2026-07 转载）。2024 年入选省独角兽。
- 员工数口径差异大：证券之星报道 537 人（研发 250+，占比近 50%，2024-02）；百度百科工商口径 172 人参保（2024）——**并列待核**（可能口径为集团 vs 单体）。

## 2. 产品线（寻访时的技术关键词锚点）

- **刻蚀设备**（多晶硅刻蚀机等，自研）、**去胶设备**（SINO Plasma 系列）、**CVD 薄膜沉积**、**ALD**、**RTP 退火**、**UV 光固化**（全自主知识产权，公司口径，2024-02）；
- 兼营：6/8 英寸设备整线搬迁、翻新再制造、零部件定制与维修（分子泵、chiller、valve、机械手）——再制造业务使其工程师对 AMAT/Lam/TEL 经典机型极熟；
- 客户：中车时代半导体（2023 年国产设备首次批量采购订单）、国家电网、中电科 55 所/214 所等 SiC/GaN 项目（校招简章/万创投行，2023-2024）；射频电源供应链被恒运昌招股书披露（2025-11）。

## 3. 人才信号（顾问最该看的部分）

- **招聘方向**：刻蚀工艺（介质刻蚀工艺经理在招）、设备技术、机械、电气、软件、装配、交付工程师（猎聘在招，2025-07）；研发投入超 1 亿元/年（2023 口径）。
- **地域**：无锡总部 + **南通如东基地（江苏邑文，制造中心，占招聘职位 81%）**、深圳分公司（职友集，2023-11）——注意岗位实际落点多在如东。
- **薪酬带**：36.2% 岗位 10–20K；本科约 22K、硕士约 17K、博士约 40K（职友集挂牌统计，2023-11，样本小仅供参考）。
- **激励**：D 轮+IPO 辅导期，ESOP 预期存在但无公开细节，待补。

## 4. 近期动态（动机与时机信号）

- 新总部基地：无锡新吴区摘地约 60 亩、总投资 7 亿元（2023）+ 总部园区项目启动（百度百科，2026）→ 扩张期；
- IPO 推进 + 化合物半导体（SiC）扩产周期 → 刻蚀/薄膜机台交付放量，工艺与交付工程师缺口；
- 招聘量 2026 年较 2025 年下降 72%（职友集口径，2026）——**信号矛盾：融资扩张 vs 挂牌收缩，需当面核实真实 HC**，可能转向猎头渠道或招聘平台切换。

## 5. 寻访角度（怎么用这份档案）

- **卖人给它**：人才池 = 北方华创、中微、屹唐、拓荆（刻蚀/薄膜大类团队）、凯世通；特色工艺侧 = 华虹、华润微、士兰微、中车时代、三安、泰科天润等 SiC 产线工艺/设备工程师（懂 8 寸机台的量产痛点）；再制造基因使其对 AMAT/Lam/TEL 服务商工程师（装机/翻新/备件背景）接受度高。
- **从它那挖人**：IPO 辅导期核心层锁定，难动；其如东制造基地装配/交付工程师对长三角设备同行是现成池子；若 IPO 受挫，2027 年起工艺骨干可能出现松动。
- **推荐定制**：突出候选人**8 英寸特色工艺机台的量产导入与良率爬坡经验**（比 12 寸先进制程背景更对口）；它重"工艺+整机"复合能力，纯机械/纯软件背景匹配度低，推荐报告里要写清候选人与客户端工艺部门的协作经历。
