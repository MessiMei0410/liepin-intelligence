# 客户档案：御微半导体（上海御微半导体技术有限公司）——公开情报版 v1

> 来源：公开情报，2026-07-24 整理；内部客户手册暂无权限，拿到后合并。
> 用途：寻访策略、推荐报告定制、候选人动机判断。

## 1. 公司定位

- 前道**光学量测/检测设备**专精特新企业：聚焦集成电路光学量检测系统设计与系统集成，形成芯片制造、掩模版制造、晶圆衬底制造、基板制造**四大领域九大类**量检测产品（公司官网；SEMI-e 展商页，2025-07）。
- 2019 年 3 月成立于上海张江（自贸区祖冲之路 899 号），**上海+合肥双基地**（合肥高新区华佗巷，合肥御微实体）；2025-02 上海金桥研发&生产基地启动（官网发展历程，2025-03）。
- 团队：研发人员占比 50%+、硕博 35%+；核心团队"亲历推动国内顶级难度复杂大型装备研发"（官网校招页，业内普遍认为有光刻机国家队背景——公开资料未明写，表述存疑待核实）。
- 融资：A 轮（2022-03，易科汇、浦东科创）；战略融资（2022-04，红杉中国、中科创星、合肥高投、上海科创投、合肥创投）（36氪创投页）。
- 出货：设备累计出货量超百台，覆盖国内主流半导体厂商（公司官网新闻，2025-07）。

## 2. 产品线（寻访时的技术关键词锚点）

- **掩模检测（拳头线）**：i6R 系列掩模表面缺陷检测（i6R-210 集检测+双面清洁+倒版，2023-08 交付先进掩模厂）、Raptor 掩模图形缺陷检测（2025-02 首台发运）、Halo 掩模基板检测（2025-07 发运 Blank Fab 版，打通"掩模全生命周期质量控制"）（官网新闻，2023-08/2025-07）。
- **晶圆检测**：i12-F300 晶圆缺陷检测、超精密晶圆缺陷检测产品（2024-05 发运）、硅片全景检测（2021-10 首台）。
- **晶圆量测**：HOUYI 套刻量测设备（2022-12 首台发运，前道 overlay 方向）。
- 关键词：明暗场缺陷检测、360° 照明、掩模/光罩质量控制、overlay 套刻量测、高精密光学系统、运动台控制。

## 3. 人才信号（顾问最该看的部分）

- **招聘方向**：光学系统设计、成像算法、精密机械/运动控制、软件、应用工程师（官网校招+社招双通道开放）；研发占比 50%+。
- **地域**：上海（张江/金桥）+ 合肥——合肥点承接中科大系光学/仪器人才，与上海点形成双城布局；HR 公开联系双城电话（官网校招页）。
- **薪酬带**：自称"具有竞争力的薪酬待遇"，具体带宽公开信息有限，待补。
- **激励**：战略轮后未披露新融资，期权情况待补；出货超百台 = 已有造血能力。

## 4. 近期动态（动机与时机信号）

- 2025-02 上海金桥研发&生产基地启动 → 产能/团队扩张信号。
- 2025-07 Halo-100 上市一周年、从掩模厂延伸至基板厂（Blank Fab）发运 → 产品线纵向打通，应用/市场团队扩编。
- 掩模检测是其最强壁垒（掩模全生命周期闭环：i6R+Raptor+Halo），先进制程与国产掩模厂（龙图光罩等 IPO）扩产直接拉动其订单 → 交付与应用工程师缺口持续。

## 5. 寻访角度（怎么用这份档案）

- **卖人给它**：目标池 = KLA（量检测全线）、Lasertec（掩模检测全球标杆）在华团队、中科飞测、东方晶源、天准半导体、精测电子、睿励；光学系统人才亦可看长光所/国望光学等院所。卖点：掩模检测国产稀缺卡位（对标 Lasertec 细分）、出货超百台的商业化验证、红杉/中科创星背书、上海+合肥双城灵活落点。
- **从它那挖人**：其掩模检测团队是国内唯一成建制的 Lasertec 替代力量，对中科飞测/东方晶源/天准及新建量检测团队（新凯来系）是精准目标；动机 = 未上市期权兑现周期长、合肥与上海双基地可能存在的内部资源博弈。
- **推荐定制**：它家重"复杂光学系统工程化"基因，推荐时突出候选人光学-机械-算法跨学科整合经历与量产机台出货记录；掩模/光罩领域客户知识（Mask Shop 流程）是稀缺加分项，纯晶圆检测背景需说明可迁移性。
