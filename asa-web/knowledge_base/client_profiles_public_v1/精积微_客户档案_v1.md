# 客户档案：精积微（上海精积微半导体技术有限公司，精测电子 300567 旗下）——公开情报版 v1

> 来源：公开情报，2026-07-24 整理；内部客户手册暂无权限，拿到后合并。
> 用途：寻访策略、推荐报告定制、判人评估器"动机信号"维度。

## 1. 公司定位

- 精测电子半导体检测体系的**明场光学缺陷检测（BFI）主体**，成立 2021-05，研发总部上海张江科学城，法定代表人马骏，注册资本 3.5 亿元（来源：c1718 转引精测电子公告，2026-04-28）。
- 股权动态：2026-04 精测电子拟出资近 2.8 亿元收购少数股权，母公司上海精测半导体持股由 21.43% 升至 35.72%，控制力增强（来源：同上，2026-04-28）。
- 下设**深圳精积微**（上海精积微持股 62.5%），2023-08 与客户签订约 1.73 亿元半导体前道检测设备销售合同（来源：仪表网转引公告，2023-08-17）。
- 母公司精测电子：泛半导体检测龙头（显示+半导体+新能源），半导体前道量检测+后道电测双线，2022 年半导体板块收入 1.83 亿元、截至 2023-04 在手订单约 8.91 亿元（来源：光大证券研报，2023-08-03）。

## 2. 产品线（寻访时的技术关键词锚点）

- **明场晶圆有图形缺陷检测设备（BFI）**：BF1100（65–180nm）为国内首个量产型号，已获突破订单并完成首套交付；BF1200（28nm）在研（来源：光大证券研报，2023-08-03）。
- 技术关键词：明场光学成像、Die-to-Die 比对、高分辨率光学、图像算法、精密运动台、晶圆缺陷分类。
- 体系内协同：上海精测（膜厚/OCD/电子束复查/CD-SEM/硅片应力）、武汉精鸿（后道老化/CP/FT）、武汉颐光/上海精卓（核心零部件与软件）（来源：精测电子董秘答复，2025-02-26）。

## 3. 人才信号（顾问最该看的部分）

- **招聘方向**（按产品线推断+体系招聘观察）：光学系统设计、图像算法/深度学习缺陷分类、精密机械与运动控制、系统集成与应用工程师——明场检测是 KLA 垄断度最高的环节之一，"光机电算软"复合岗缺口大。
- **地域**：上海张江（研发）+ 深圳（精积微华南交付/销售）+ 武汉（集团大本营）三地。
- **薪酬带**：公开渠道未见精积微单独挂牌带宽，**待补**；可参考上海半导体量检测同行（中科飞测/睿励）硕士研发 25–40k 区间校准。
- **激励**：本轮母公司收购少数股权，涉及员工持股平台（上海精望企业管理中心）股权变动——**激励结构变化期 = 骨干观望窗口**（来源：c1718，2026-04-28）。

## 4. 近期动态（动机与时机信号）

- 2026-04 母公司近 2.8 亿元加码控股：资源整合、平台化推进，整合期通常伴随岗位调整与激励重排（来源：c1718，2026-04-28）。
- 国产量检测赛道持续放量：精测体系在手订单充足，BF1200（28nm）攻关阶段 = 高端光学/算法人才需求紧迫。

## 5. 寻访角度（怎么用这份档案）

- **卖人给它**：明场检测直接对手 = 中科飞测、上海睿励、御微半导体；外资池 = KLA（科磊）上海/深圳、AMAT 过程诊断部门；图像算法岗可放宽至机器视觉大厂（海康/华睿）+ 半导体背景组合。卖点：国内唯一量产明场机型+精测上市平台+28nm 攻关项目履历含金量。
- **从它那挖人**：股权收购整合期是触达窗口；其光学/算法工程师对中科飞测、睿励、KLA 均有直接溢价；张江人才竞争白热化，流失风险高。
- **推荐定制**：强调候选人在 KLA/AMAT/中科飞测的机型量产经验与工艺节点（28nm 以下优先）；体系内调动（精测↔精积微）需注意客户 restricted 条款。
