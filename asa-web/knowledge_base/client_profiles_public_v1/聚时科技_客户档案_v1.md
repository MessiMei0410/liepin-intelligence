# 客户档案：聚时科技（Matrixtime，B 轮）——公开情报版 v1

> 来源：公开新闻/融资披露/招聘平台，2026-07-24 整理；内部客户手册暂无权限，拿到后合并。
> 用途：寻访策略、推荐报告定制、判人评估器"动机信号"维度。

## 1. 公司定位

- 工业 AI+半导体视觉检测设备商，2018 年 3 月成立，总部上海虹桥商务区；国家级专精特新"小巨人"；创始人/CEO 郑军博士（据亿欧/投资界，2021-12/2025-10）。
- 定位"AI 赋能集成电路制造"：**AI 驱动的半导体缺陷检测量测设备（聚芯 MatrixSemi 系列）+AI 良率分析与管理系统**，制程覆盖前道 Fab、先进封装、硅片制造与后道（据 DoNews，2025-10）。
- 2025-10 完成数亿元 B 轮融资（上海科创集团、松江国投、绍兴越城区集成电路产业基金等）；此前股东含韦豪创芯、中芯聚源、汇川技术、华兴源创、北京集成电路尖端芯片基金等产业资本（据投资界/新浪财经，2025-10）。
- 团队：硕士及以上占比 95%，30+ 博士，核心来自贝尔实验室、西门子、华为、ASM 等（据亿欧，2021-12）；猎聘口径公司规模 100–499 人。

## 2. 产品线（寻访时的技术关键词锚点）

- **聚芯系列检测设备**：聚芯 6000（先进封装 Bumping/TSV/CIS 2D/3D 检测量测）、聚芯 6300（前道光刻/CMP/刻蚀/显影工艺缺陷检测分析）、聚芯 6500（前道 Particle 颗粒检测）、聚芯 3000（芯片外观/微小器件 2D/3D 量测）、聚芯 2000（引线框架/IC 载板外观检测）、聚芯 5000（AI 缺陷分类 ADC+一站式良率管理）（据 DoNews，2025-10）；
- **核心技术栈**：大规模深度学习（MatrixVision 模型库）、2D/3D 机器视觉、明场/暗场/多光谱复杂成像、光谱共聚焦/白光干涉、精密光机与运动控制、AI 工控/机器人视觉（据公司官网/集微网，2021-11）；
- 另有光伏 AI 检测（首个硅片 AI 检测无人车间案例）、机器人 AI 业务线；
- 产能布局：上海松江（精密制造工厂+无尘车间）、上海张江无尘车间、浙江绍兴无尘车间；深圳、长沙/绍兴设研发分中心（据投资界，2025-10）。

## 3. 人才信号（顾问最该看的部分）

- **招聘主力方向**：深度学习/CV 算法、光学成像系统（明/暗场多光谱）、精密机械与运动控制、FPGA/底层加速、设备整机软件、应用工程师——**"AI 算法+光学+精密整机"三栖是标配要求**；
- **地域**：上海（总部+松江工厂+张江）、深圳、长沙、绍兴；猎聘显示 HRBP 在招活跃（30+ 招聘相关岗位在线，2026 年）；
- **薪酬带参考**：公开挂牌数据有限，待补；猎聘标注"周末双休、弹性工作、年底多薪"（据猎聘公司页，2026 年）；
- **激励**：B 轮到位，产业资本背书；期权池安排公开信息有限，待补；
- 猎头友好度：100–499 人规模+扩产（B 轮资金明确用于扩产线、加大市场拓展），中高端岗位外采意愿大概率较高。

## 4. 近期动态（动机与时机信号）

- **B 轮数亿元到账（2025-10）**：明确投向产品迭代+扩半导体设备产线+市场拓展 → **扩编窗口期，销售/交付/制造岗先行放量**；
- 产品线从后道/先进封装向**前道 Fab（6300/6500 系列）延伸**——前道验证周期长，应用与算法人才需求前置；
- 绍兴越城区基金入股+绍兴建无尘车间 → 长三角扩产，绍兴驻点岗位新增；
- AI+检测赛道拥挤（中科飞测、精测电子、赛腾、凌云光均在加码），**人才竞价战激烈**；
- 未上市+检测赛道头部集中化，若后续融资/IPO 节奏不及预期，早期员工存在观望情绪（推断，需访谈验证）。

## 5. 寻访角度（怎么用这份档案）

- **同行对手/人才池**：直接竞对为中科飞测（深圳，光学检测+AI 软件）、精测电子（上海/武汉）、东方晶源（北京）、赛腾股份、凌云光；算法岗可挖商汤/旷视/海康威视研究院的工业视觉团队；光学岗可挖 KLA、康代（Camtek）、奥宝（Orbotech/KLA）在华团队；
- **最缺岗位**：前道检测算法（缺陷检测/分类）、复杂光学系统工程师、整机系统集成、大客户销售与 FAE（B 轮后市场拓展是资金主投向）；
- **卖人给它**：讲"AI+光学+整机全栈自研+产业资本（中芯系/韦豪）订单通道+小团队高天花板"，对大厂算法候选人讲"模型直接上产线、不内卷"；
- **从它那挖人**：其"算法+光学+半导体 knowhow"复合工程师是中科飞测/精测/KLA 的争抢对象；动因人群 = 未上市期权变现远、想进大厂拿确定性现金包的算法工程师；
- **推荐定制**：候选报告突出"算法落地到设备量产"的闭环经历（纯互联网算法背景不匹配）；博士密度高，技术面试深，推人前先做技术预筛。
