# 客户档案：大族激光（002008.SZ，半导体/泛半导体业务线）——公开情报版 v1

> 来源：公开情报，2026-07-24 整理；内部客户手册暂无权限，拿到后合并。
> 注意：主业为激光装备，本档案只覆盖半导体/泛半导体相关子公司线。

## 1. 公司定位

- 全球激光装备前三、亚洲第一；2025 年营收 187.59 亿元（+27.00%）、归母净利 11.90 亿元（-29.77%）、扣非净利 8.10 亿元（+82.28%）（来源：大族激光 2025 年报，2026-04-17）。
- **半导体设备（含泛半导体）业务 2025 年营收 20.41 亿元（+15.00%）**，为四大板块之一；2026Q1 集团营收 51.35 亿元（+74.44%）（来源：年报；同花顺，2026-06-16）。
- 半导体板块"三驾马车"：大族半导体（全资）、大族光电（控股，拟分拆创业板）、上海大族富创得（持股 76.5%）；另有 PCB 设备主体大族数控（301200，持股约 84%，2026-02 已港股上市）。

## 2. 产品线（寻访时的技术关键词锚点）

- **大族半导体**（2025 营收 13.78 亿元，+23.89%）：激光表切/全切、激光内部改质切割、刀轮切割（前道晶圆切割）；国产首台激光解键合设备（2017）、SiC 剥片设备（行业主流）、金刚石激光剥离工艺已产品化；晶圆级/面板级激光解键合国内份额前列（来源：2025 年报；OFweek，2026-06-15）。
- **大族光电**：焊线机（金/铜线，对标 ASM/K&S）、固晶机、测试分选/编带——LED 封装国产替代龙头；2026-07 公告拟分拆至创业板上市（来源：艾邦半导体网，2026-07-22）。
- **上海大族富创得**：SMIF/EFEM 晶圆传输系统、LoadPort/Aligner/Robot，8 寸晶圆厂 SMIF 市占率约 85%，客户含中芯国际、英特尔、AMAT、KLA；2023 营收约 3.5 亿元；2025-11 完成 B 轮（盈远投资）、落地无锡基地、设立绵阳子公司；2025-12 终止上市辅导（来源：百度百科，2026-01-04；液晶网，2025-11-24）。
- 显示/泛半导体：激光打孔机（单台 1 亿元，获复购）、激光修复/剥离机，中标京东方、华星光电产线（来源：2025 年报）。

## 3. 人才信号（顾问最该看的部分）

- **招聘方向**：激光工艺（超快/紫外）、精密运动控制、机器视觉、封测设备机械/电控/软件、晶圆传输机器人；集团研发人员 6,645 人、研发投入 20.84 亿元（2025 年报）。
- **地域**：深圳（总部+大族半导体/大族光电）、上海（富创得）、无锡/绵阳（富创新基地）——多地点便于异地人选落位。
- **薪酬带**：公开带宽分散（深圳工程师普遍 15–30k 区间），具体**待补**。
- **激励**：上市公司+子公司分拆/融资并行（大族光电分拆、富创得 B 轮）= 子公司层面期权/股权窗口多，**卖人时可打"子公司独立上市期权"牌**；反向看，分拆辅导终止（富创得 2025-12）也会造成激励预期落空的动因人群。

## 4. 近期动态（动机与时机信号）

- 大族光电分拆创业板（2026-07 公告）→ 封测设备团队架构/汇报线调整期。
- 富创得终止上市辅导后转 B 轮融资+无锡/绵阳扩产 → 传输设备方向持续招人。
- 集团 2026Q1 高增长、东南亚 1.5 亿美元海外运营中心（2026-02 公告）→ 海外服务/交付岗需求上升。

## 5. 寻访角度（怎么用这份档案）

- **卖人给它**：晶圆切割/激光工艺池 = Disco、东京精密在华团队、德龙激光、光力科技；封测设备池 = ASMPT、K&S 中国、长川科技、华峰测控、新益昌、金海通；晶圆传输池 = RORZE、Hirata、Brooks 在华团队。卖点：激光自研率 80% 的垂直一体化平台+多个子公司资本化窗口。
- **从它那挖人**：体量大、事业群制，子公司分拆期骨干观望；深圳工程师向设备同行（中微、拓荆、长川）流动成熟；富创得的 EFEM/SMIF 人才对国产整机厂（北方华创、中微）极稀缺。
- **推荐定制**：区分对接主体（大族半导体/大族光电/富创得用人标准不同）；突出候选人"激光+精密运动控制+视觉"复合项目经历与对标 Disco/ASM 机型的量产数据。
