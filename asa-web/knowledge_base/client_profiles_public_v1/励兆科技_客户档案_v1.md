# 客户档案：励兆科技（上海励兆科技有限公司）——公开情报版 v1

> 来源：公开情报，2026-07-24 整理；内部客户手册暂无权限，拿到后合并。
> 用途：寻访策略、推荐报告定制、判人评估器"动机信号"维度。

## 1. 公司定位

- **半导体设备射频/等离子体系统（核心零部件）供应商**，成立 2022-08，研发中心上海闵行（办公+实验室超 1,000㎡），制造基地上海临港（约 5,000㎡）（来源：上海工程技术大学就业网企业宣讲，2025-12-05）。
- 切入"卡脖子"环节：射频电源+匹配器+远程等离子源（RPS），此前 MKS、AE、Daihen、Kyosan、霍廷格等外资垄断 95% 以上份额，国内市场规模约 50 亿元（来源：钛媒体，2023-09-04）。
- 团队规模：2025-01 融资口径"已发展到近百人"，其中研发团队近 50 人；国家高新+专精特新（来源：阿里云创业者社区转引投资界，2025-01-07；就业网宣讲，2025-12-05）。
- 核心人物：创始人赵馗博士（高频电力电子，团队 2012 年起深耕）；首席科学家为上海交大副教授/博导；副总裁宋伟（前爱思强中国区总经理，历任 Varian/AMAT/MKS/Kateeva 高管）（来源：钛媒体，2023-09-04）。

## 2. 产品线（寻访时的技术关键词锚点）

- **射频电源**：13.56MHz / 400kHz 系列，功率可调精度 0.1W、脉冲频率 2Hz–50kHz、占空比 1%–99%，自研 MOFT（模型导向自动调频）实现亚毫秒级阻抗匹配（来源：钛媒体，2023-09-04）。
- **自动阻抗匹配器、远程等离子体源（RPS）**：12 寸晶圆去胶/氧化/清洁用 RPS 在开发送样（2023 口径）；定制模块：ESC 高压模块、直流偏压探测器、射频滤波器（来源：36氪创投平台）。
- 应用覆盖刻蚀 Etch、ALD/ALE、PVD/CVD、去胶 Strip、注入 Implant 等大部分干法制程——**下游是整机厂而非 Fab**。
- 关键词：高频电力电子、射频匹配算法、Smith 圆图、脉冲调制、等离子体控制。

## 3. 人才信号（顾问最该看的部分）

- **招聘方向**：射频/电力电子硬件、嵌入式与高速数字控制、匹配算法（需数理背景+懂等离子体工艺）、销售/应用工程师；BOSS 直聘持续在招（来源：BOSS 直聘公司页，2026-06-05）。
- **地域**：上海闵行（研发）/上海临港（制造），单一城市，全国挖人需 relocation 方案。
- **薪酬带**：公开未披露，**待补**；初创阶段通常"现金中位+期权"组合。
- **激励**：Pre-A（2023-09，砺思资本/中芯聚源/临港科创投）+ Pre-A++（2025-01，金浦智能领投）两轮融资，期权池新鲜、估值上升期 = **卖人时"早期股权"是核心卖点**（来源：投中网/阿里云，2025-01-07）。

## 4. 近期动态（动机与时机信号）

- 产品"已进入国内多家设备龙头与晶圆制造大厂"（金浦智能口径，2025-01），客户验证放量阶段 = 应用/交付/销售岗持续扩编。
- 两年三轮融资节奏快、临港基地投产，处于"研发型团队→量产型公司"转型期，急需有外资大厂量产与体系化经验的中层。

## 5. 寻访角度（怎么用这份档案）

- **卖人给它**：首选池 = MKS/Advanced Energy（AE）/Daihen/Kyosan/霍廷格（Hüttinger）在华射频团队；次选 = 北方华创、中微公司射频与匹配器部门、等离子体源厂商（中科科仪等）；高频电力电子学术圈（上海交大/浙大）博后。卖点：国产射频电源第一梯队卡位+科学家团队+中芯聚源等产业资本背书。
- **从它那挖人**：上升期初创，核心团队绑定深、挖人难度高；可关注的是早期加入、岗位被空降高管挤压的中层工程师，以及临港工厂量产岗。
- **推荐定制**：强调候选人"射频+等离子体工艺"复合背景（纯电源工程师不够用）；它家重算法与工艺协同，推荐报告需呈现候选人调频/匹配算法的具体项目数据。
