# 客户档案：富创精密（沈阳富创精密设备股份有限公司，688409.SH）——公开情报版 v1

> 来源：公开情报，2026-07-24 整理；内部客户手册暂无权限，拿到后合并。
> 用途：寻访策略、推荐报告定制、判人评估器"动机信号"维度。

## 1. 公司定位

- 国内**半导体设备精密零部件龙头**（第一梯队），成立 2008 年，总部沈阳；全球少数可量产应用于 7nm 制程半导体设备的精密零部件厂商（来源：新浪财经研报，2026-05-26）。
- 业绩：2024 年营收 30.4 亿元（+47.14%）、归母净利 2.03 亿元；2025H1 营收 17.24 亿元（+14.44%）、归母净利 0.12 亿元（-89.92%，因产能/人才前瞻性投入）；2026Q1 营收 10.43 亿元（+36.84%）、归母净利 0.58 亿元（+361.52%）（来源：华源证券研报，2025-09-26；经传多赢个股页，2026-07）。
- 产能布局：沈阳（大本营）、南通（IPO 募投，2024 投产）、北京（部分验收）、新加坡（服务海外龙头客户）（来源：华源证券研报，2025-09-26）。
- 市场空间：2025 年全球半导体零部件市场超 600 亿美元、中国大陆超 263 亿美元（SEMI 数据推算口径，同上）。

## 2. 产品线（寻访时的技术关键词锚点）

- **机械及机电零组件**（2024 年占营收约 69%）：工艺零部件（腔体、内衬、匀气盘）、结构零部件、腔体模组、阀体模组——应用于 ETCH/CVD/PVD 腔体（来源：华源证券研报，2025-09-26）。
- **气体传输系统**（约 29%）：气柜（百余种设计方案，大部分量产）、气体管路，用于 ETCH/ALD/CVD/外延/RTP 设备。
- 技术关键词：精密机械制造、高洁净度表面处理（电解抛光/钝化）、特种焊接、洁净清洗、模组化组装、气柜管路。

## 3. 人才信号（顾问最该看的部分）

- **招聘方向**（按业务推断）：精密加工工艺（CNC/钣金/焊接）、表面处理工艺、质量/计量工程师、气柜设计与装配、NPI/制造工程师、大客户经理（对接北方华创/中微/AMAT）。
- **地域**：沈阳、南通、北京、新加坡四地建厂——异地调动与新基地开荒岗多，异地候选人有落点。
- **薪酬带**：公开挂牌带宽未见系统数据，**待补**；沈阳制造业薪酬基数低，南通/北京基地对长三角候选人需谈溢价。
- **激励**：上市公司（科创板），限制性股票工具可用；2025H1 利润承压期+股价波动（2025-10 约 75 元→2026-07 约 194 元，区间大涨）= 激励价值随行情波动大（来源：搜狐证券行情，2026-07）。

## 4. 近期动态（动机与时机信号）

- 2025H1 净利大降 89.92%（扩产+人才前置投入），2026Q1 营收/利润双修复——"先投入后收获"叙事，人才端处于**扩产抢人周期**（来源：华源/经传多赢）。
- 新加坡基地服务海外龙头 = 英语+SEMI 标准体系背景人才需求上升。

## 5. 寻访角度（怎么用这份档案）

- **卖人给它**：直接同行池 = 新莱应材、珂玛科技、中瓷电子、富乐德、靖江先锋；外资池 = Ichor、UCT（超科林）、世伟洛克、富士金在华工厂；整机厂反向流动（北方华创/中微的工艺与供应链人才懂零件规格，适配其模组化转型）。卖点：零部件第一股+全球化产能+从"零件"向"模组/系统"升级的技术纵深。
- **从它那挖人**：利润承压+扩产期内卷，一线工艺/质量工程师易被整机厂和新建零部件厂溢价挖走；沈阳基地骨干对长三角/新加坡机会敏感度高。
- **推荐定制**：突出候选人"机加工+表面处理+洁净标准"全链路经验及对应设备类型（ETCH/CVD 腔体优先）；英语与海外客户服务经历对新加坡基地岗位是硬加分。
