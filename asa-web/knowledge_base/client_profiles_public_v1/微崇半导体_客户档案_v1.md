# 客户档案：微崇半导体（上海微崇半导体设备有限公司 / 微崇半导体（北京）有限公司）——公开情报版 v1

> 来源：公开情报，2026-07-24 整理；内部客户手册暂无权限，拿到后合并。
> 用途：寻访策略、推荐报告定制、候选人动机判断。

## 1. 公司定位

- 创新**前道量检测设备**公司：立足**非线性光学/二谐波（SHG）晶圆检测技术**，"以光测电"、无损在线检测晶圆内部晶格缺陷与电学特性——技术路径为全球原创（"全球唯二、中国唯一"口径，巅云创新页，2025；解放日报，2026-03-12）。
- 2021 年 3 月创立于上海杨浦（长阳创谷，建有千级洁净车间研发与生产基地）；另有北京主体（大兴，2021-08 注册）（解放日报，2026-03；36氪创投页）。
- 创始人/董事长/CEO 黄崇基（1993 年生，美国超快激光/材料博士，曾在美国头部半导体检测设备公司参与世界首台二谐波在线检测机台开发并负责核心系统设计；2023 福布斯中国 30U30）（百度百科，2026-05）。
- 融资密集：天使（2021-09，武岳峰、云启）→Pre-A（2022-02，云启）→Pre-A+/++（2022-11，中芯聚源、临芯）→A 轮 1 亿元（2023-08，临芯、新潮创投等）→A+（2025-02，金雨茂物、赛纳资本、光谷半导体产投）→**B 轮（2026-01，首都科技发展集团）**；累计公开口径约 2.1 亿元（亿欧数据，2026-04）。

## 2. 产品线（寻访时的技术关键词锚点）

- **ASPIRER/ASPIPER 3000**：二谐波晶圆缺陷检测系统（国内首台该路径机台），界面/膜层质量综合分析，有无图案晶圆均适用；独特场景：DRAM 锗硅（GeSi）超薄膜层（10nm 内）锗比例与厚度在线监测（CSEAC 圆桌发言，2025-09）。
- **BRAVERY 3000**：热波/光调制反射量测，聚焦**离子注入**工艺环节（替代进口）（解放日报，2026-03）。
- **CLARITY 1000/3000**：超声波扫描显微镜，晶圆键合后空洞/裂纹检测（先进封装方向）（SEMI-e 展商页，2025-07）。
- 三款产品已进入国内最先进晶圆厂、完成客户验证并获复购（解放日报，2026-03-12）。
- 关键词：二次谐波 SHG、非线性光学、超快激光、光调制反射（PMR）、热波、离子注入监测、超声扫描 SAT。

## 3. 人才信号（顾问最该看的部分）

- **招聘方向（推断）**：非线性光学/超快激光博士级研发、光学系统工程、系统软件、应用工程师（客户端定制化开发是其打法）；团队"高学历 90 后为主"（解放日报，2026-03）。
- **地域**：上海杨浦（长阳创谷）+ 北京（大兴）；北京 B 轮由首都科技发展集团领投 → 北京基地大概率扩编。
- **薪酬带/激励**：公开信息有限，待补；早期员工期权价值随 B 轮走高。
- 团队文化："不只是国产替代，要做全世界还没有的机台"（临芯投资评语，2022-11）→ 吸引的是技术理想型候选人。

## 4. 近期动态（动机与时机信号）

- 2026-01 B 轮落地（首都科技发展集团）→ 资金到位后的**扩编窗口**；创始人自述"从 0 到 1 完成，正进入从 1 到 10 市场推广阶段"（解放日报，2026-03）→ 市场/应用/客服团队前置搭建。
- 产品获头部晶圆厂复购 + DRAM GeSi 监测独家场景 → 存储客户扩产周期直接受益。
- 探索上市或与产业资本合作可能（创始人表态，百度百科口径）→ 中期存在 IPO 前人才储备需求。

## 5. 寻访角度（怎么用这份档案）

- **卖人给它**：目标池极窄——KLA/Onto 光学检测研发、美国那"另一家"二谐波设备公司（Onto Innovation 系）背景、超快激光/非线性光学博士（高校+研究所）、中科飞测/御微等光学检测同行；应用岗可从 Fab 厂量测/注入工艺工程师转。卖点：全球原创技术路径（论文级工作直接变产品）、B 轮资金+头部 Fab 复购背书、年轻团队无大厂病、杨浦/北京双点。
- **从它那挖人**：其光学研发骨干是"非线性光学+半导体设备工程化"的稀缺复合体，对新凯来系、中科飞测、东方晶源极具吸引力；但团队技术信仰浓度高、B 轮刚落地，当下挖角难度高——更现实的切入是应用/销售层与后续融资间隔期的观望者。
- **推荐定制**：研发岗重"超快激光/SHG 物理功底+系统工程能力"双重证据（论文+机台经历）；应用岗重 Fab 厂量测工艺经验与定制化开发响应速度。推荐报告应突出候选人对"以光测电"技术路线的理解深度，常规光学检测背景需论证迁移路径。
